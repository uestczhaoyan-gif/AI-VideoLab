# code-motion 风格模板

执行器读取 `content.style`，从本目录选择 `<style>.html`。三个模板都是**本地确定性 HTML**，按下载资源中的视觉语言改写，不是直接运行上游工程。

| style | 来源资源 | 视觉规则 | 适合 |
| --- | --- | --- | --- |
| `blueprint` | `resources/styles/lemo-opuscar/source/styles/blueprint/` | 深蓝底、技术网格、单色线稿、光学/工程标注、等宽字 | 原理、光路、结构、工程解释 |
| `bauhaus` | `resources/styles/mg-styles-15/source/prompts/09-bauhaus.md` | 米色纸底、黑/红/蓝/黄几何、粗黑标题、拼贴块 | 概念、对比、色彩/形状主题 |
| `ink-wash` | `resources/styles/lemo-opuscar/source/styles/ink-wash/` | 宣纸底、墨线圆环、留白、宋体、印章 | 诗意、时间、波/场、东方视觉 |

## 使用

```sh
npm run make -- --topic "透镜如何改写一束光" --style blueprint --duration 20 --yes
```

不传 `--style` 时用通用模板 `../scene.template.html`。

## 新增风格

复制一个现有模板，修改布局与 `window.render(t)`；保持不依赖 Date/random/网络，输出与帧号确定性对应，然后在 `tools/studio/create.mjs` 的 `--style` 校验路径下即可使用。

## 详细 Prompt（复刻这三个模板）

### blueprint

> 16:9 技术蓝图短片。深海军蓝背景叠加 3.2rem 工程网格，四角取景框，左上等宽大写 kicker；标题使用亮白色等宽粗体，副标题低饱和青蓝。中央一条虚线光轴，物体箭头、薄透镜椭圆、焦点和倒立实像；光路分三段（平行光→透镜、过焦点、出射）按时间逐段画出，线段使用青色发光线与虚线端点。左下三张步骤卡按时间点亮，右下 HUD 显示 t / frame / 规格。禁止摄影、渐变噪点、3D 渲染；只保留矢量线稿与打字机标注。

### bauhaus

> 16:9 包豪斯几何短片。米白纸底，黑/红/蓝/黄四色；左上大号黑色粗体标题，允许一个词用红色强调；右上细线 HUD。三个大几何体（黄圆、红圆、蓝方块）在画面右侧缓慢位移/旋转；左下黑色三角形棱镜，一束黑光进入后分裂为红橙黄绿蓝紫六条线，按波长依次出现。左下三块黑/红/蓝步骤卡，右下规格。不要阴影、渐变、纹理；纯平涂、硬边、粗线。

### ink-wash

> 16:9 水墨光学短片。宣纸米色底，细微纸纹；左上宋体标题，副标题低饱和墨色；右上等宽小字 HUD。两个波源 S1/S2 发出同心墨线圆环，随时间扩散并交叠；下方一条墨色干涉波形，振幅随相位变化；右侧朱红印章。整体留白 60% 以上，不出现实拍、3D、彩色渐变；墨色只用 #1d2624，朱红只用 #a4532f。

## 边界

- 光学内容为演示，不是学科审稿材料。
- 模板是手工改写；上游模板的完整工程/媒体仍在 `resources/`，遵守原许可。
- 新增风格必须保持 `window.render(t)` 确定性，不依赖 Date/random/网络。
