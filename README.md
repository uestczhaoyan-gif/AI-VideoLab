# VideoLab

研究可复现、可选择、可迁移的 AI 视频制作方法，逐步沉淀为面向不同视频用途的开源 Workflow 与 Skill。

覆盖产品与项目介绍、知识解释、叙事与电影感短片等方向。视觉风格与制作技术独立选择；光学科普是候选案例之一。

## 推进方式

1. 观看参考作品，追溯作者方法与工程。
2. 复现原作的关键效果，对照成片和源码拆解设计决策及实现方式。
3. 依据新的创作想法重新设计并编写代码，用新概念验证可迁移的方法。
4. 将有证据支持的方法整理成 Workflow，再封装成 Skill。

样片、可编辑工程、完整输入、运行记录和失败案例共同构成研究结果。可运行不等于好看，单个精彩样片也不等于方法已经通用。
