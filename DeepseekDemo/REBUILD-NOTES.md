# 复原笔记：从文档到成片

目标不是“再跑一次上游源码”，而是检验一个问题：**项目里已经写下的设计与方法笔记，够不够重写一遍这条片子。**
所以本次只用文档 + 参考帧，没有打开上游 `demos/02-line-art/film.js`。

## 1. 从文档里拿到的硬约束

- 叙事是一条线：种子 → 树苗 → 屋檐/房子 → 天际线 → 山脊与浪尖环 → 标志 → 填金 → 字标。
- 视觉语言：等宽细线、单色金、大量负空间、线条连续生长、只有一次线面转换。
- 迁移的是“连续的形体关系、可追踪的笔尖、局部到整体的镜头、速度变化、一次线面转换、
  与运动相关的声音”，城市与固定秒数不必复制。
- 先规划“观众依次看懂什么”，再规划“线怎么连过去”；旧图形不能干扰当前主体。
- 声音读公共事件表，笔触声跟绘制包络走。

这些约束直接决定了实现的骨架：一条 `pieces` 序列 + 一个事件表（`cues.json`），
不是若干个可以自由剪辑的镜头。

## 3. 把连续的线组织成一条可画的路

`cues.json` 的 `pieces` 是一条路的顺序表，每一段就是一笔：

```
approach → seed → stem-a → leaf-low → stem-b → leaf-mid → stem-c → leaf-high
→ stem-top → eave → house → tower-slab → tower-step → dome → spire
→ runway → wave → hill → ring
```

几处关键设计：

- **叶子**是“从茎上出去再回来”的小透镜。第一版用眼估的控制点，出来是尖喙；
  改成先定叶轴（附着点 → 叶尖）与半宽，再按法向偏移生成两条贝塞尔，才得到叶片。
- **屋檐**是双层：先出到 x=656 折返，再回写到房子的左墙 x=444，于是“屋顶板”有了厚度。
- **天际线**是基线上的一个个“凸起”：正面墙上行、过顶、背面墙下行、回到基线再前进。
  这样一条线可以画出一整座城市而不回描。
- **浪尖环**是一个真正的自交环：上行到浪峰、向内绕一圈、从入口旁穿出，接山脊。
- **圆环**用解析圆（`circle` 段）而不是 SVG 的 `A` 命令，原因见第 6 节。

## 4. 时间：从参考成片的节拍反推

用 0.5 s 间隔的联系表读节拍，得到（上游成片）：

| 时间 | 画面 |
| --- | --- |
| 0.2–0.6 | 水平线从画外进入，卷起种子 |
| 1.0–1.8 | 茎上升、三片叶依次出现 |
| 2.2–2.6 | 茎顶折向右侧成为屋檐 |
| 3.0–3.4 | 房子（拱门） |
| 3.6–4.2 | 斜面塔、退台楼 |
| 4.4–5.0 | 穹顶楼、尖顶楼 |
| 5.2–5.8 | 基线向右长跑，镜头拉开看整座城 |
| 6.0–6.6 | 浪峰绕环 |
| 6.8–7.2 | 山脊向左回走 |
| 7.0–7.4 | 圆环 + 拱门 |
| 7.4–7.8 | 金色由线转面 |
| 8.0–8.6 | 反向光脉冲 + 镜头退回整幅 |
| 8.4–9.4 | 字标与副标 |

本次实现（`cues.json` 的 `start/end`）与之对齐到 ±0.2 s：

| 段 | 时间 | 段 | 时间 |
| --- | --- | --- | --- |
| approach | 0.00–0.34 | runway | 5.10–5.80 |
| seed | 0.34–0.80 | wave | 5.80–6.36 |
| 三片叶 | 1.02–1.96 | hill | 6.36–6.84 |
| eave | 2.04–2.50 | ring | 6.84–7.16 |
| house | 2.50–3.10 | arch | 7.16–7.44 |
| tower-slab / step | 3.10–4.12 | fill | 7.34–7.66 |
| dome / spire | 4.12–5.10 | pulse | 7.62–8.28 |
| — | — | 字标 / 副标 | 8.26 / 8.72 |

笔速不再按段写死缓动，而是把“每段收笔时刻 ↔ 累计弧长”丢进单调三次插值，
得到 C1 连续的弧长—时间曲线：转角处自然减速，长直线自然加速，没有分段接缝的速度跳变。

## 5. 镜头：跟着笔尖，但别被笔尖拖着甩

第一版是手写镜头关键帧，问题是“跟不准”：参考片里笔尖基本稳定在画面 40–55% 的位置，
手写关键帧只能在抽样点上勉强对上。

改成模型化：

```
cx = 平滑后的笔尖 x + lead(t) / z
cy = 平滑后的笔尖 y + leadY / z
结尾 8 s 左右把镜头交还给整幅构图（mix 到 960,540,1.0）
```

- `z` 自己走一条关键帧曲线：开场 2.35 特写树苗，看城时退到 0.78（“呼一口气”），
  结尾回到 1.0。
- 笔尖位置取 ±0.34 s 的加权平均，否则画圆环时镜头会绕圈猛甩。

这条模型比手写关键帧更接近原片的“手跟拍”质感，也更好扩展到新题材。

## 6. 踩到的坑（值得写进方法）

1. **SVG 的两段 `A` 拼不出整圆。** 用 `A r r 0 0 0 p1` + `A r r 0 0 0 p0` 画整圆时，
   两条弧可能选中不同的候选圆心，结果不是圆而是一片“花瓣”，
   在本片里表现为标志下方一条莫名其妙的亮弧。
   解决：圆环改为按角度解析采样（`circle: {c, r, a0, dir}`），拱门用两段三次贝塞尔近似。
2. **圆面填金要在离屏画布里“挖洞”。** 直接在主画布 `destination-out` 会把背景和线条一起擦掉。
   做法：离屏画布画金色圆面 → `destination-out` 挖拱门 → 用“从线落点向外扩张”的径向遮罩做揭示
   → 整张贴回主画布。
3. **叶片不是随便两点加曲线。** 必须用叶轴 + 半宽 + 法向偏移，才能得到有尖有肚的叶子。
4. **填金残影。** `drawImage` 之前若 `shadowBlur` 没归零，会在圆面外留下脏边。
5. **镜头不能直接等于笔尖。** 必须时间窗平滑，并让 `lead` 可以随段落变化。
6. **开场的引导线。** 参考片的路径从画面外很远的地方起笔（开场是一条长线进入）；
   本次为了保住结尾的完整构图，把起点放在 x=-560：结尾时基线会从画面左边缘进入，
   而参考片是停在画面内约 10% 处。这是**已知差异**，见第 7 节。

## 7. 与原片的差异（如实记录）

| 项目 | 参考片 | 本次实现 |
| --- | --- | --- |
| 路径起点 | 画面外很远处起笔，结尾时线条止于画面内 ~10% | 起点 x=-560，结尾线条从画面左边缘进入 |
| 子路径走法 | 房子更接近“右墙先下、地面回描” | 左墙先下，地面正向走 |
| 镜头数值 | 逐帧真实值未知 | 在 10 个抽样时刻上对齐，中间为插值 |
| 节奏 | — | 与参考节拍对齐到 ±0.2 s |
| 拱门 | 推测属于连续笔画（被填金遮住） | 单独绘制，笔尖光跟随，视觉等价 |
| 配乐 | 上游自有音轨 | 本次新写（D 大调），不复制 |
| 字标 | 宽约 690、基线 884 | 同位置重排；字距/字号按本机字体重新拟合 |
| 颗粒/调色 | 上游参数未知 | 屏模式叠加颗粒 + 径向暗角，目测对齐 |

结论：**结构与观感可复原，逐像素不可复原**——像素级一致需要上游 `cues.json` 与镜头数据，
而文档里没有这些值。把它们补齐正是这次实践反推出来的东西（见 `docs/METHOD.md` 第 7 节）。
