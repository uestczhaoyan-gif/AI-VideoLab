# TWO POINTS · 两点之间

一分钟一笔画科普短片：**分辨率**。一条线从一粒光出发，走过波前、透镜、艾里斑，
画出“两个点靠得太近就只剩一团”，再用算法的三层剖面把它读回来，最后收成一个带两个孔的圆。

## 为什么这个题适合一笔画

选题只有一个标准：**它本身是不是一条连续的形变链。**
分辨率的故事恰好是：一个点 → 一圈波 → 一个透镜 → 一个焦点 → 一个斑 →
两个斑叠在一起 → 一团 → 一串样本 → 两个点。每一步的“尾”都是下一步的“头”，
不需要剪切、不需要旁白硬接。

而且它的结论可以落在**一个圆**里：圆面（光圈）+ 两个孔（两个被分辨的点）。
一笔画的招牌动作“线转面”在这里不是装饰，而是论点本身：
**模糊被算开，两个点留在光里。**

## 分镜（60 秒）

| 时间 | 形体 | 字幕 |
| --- | --- | --- |
| 0–1.5 s | 画面中央亮起一个点 | — |
| 1.5–7.5 s | 点卷出 2.4 圈螺旋：波前 | 一个点，发出的是圈圈的波 |
| 7.5–11 s | 线右行，立起一枚透镜（竖着的“叶片”） | 透镜把波收成一个焦点 |
| 11–14 s | 反向螺线收拢到焦点（螺旋越转越小） | — |
| 14–17.6 s | 焦点炸开成三层同心环：艾里斑 | 可焦点不是一个点，是一个斑 |
| 17.6–22.2 s | 走到第二个点，再画一组环：**两个点的斑分得开** | — |
| 22.2–27.8 s | 两个点靠到 70 px，两组环叠在一起：**只剩一团** | 两个点靠得太近，只剩一团 |
| 27.8–33 s | 一团被“采样”：第一层剖面（一个宽包） | 模糊里还有信息，只是没人读 |
| 33–38.8 s | 第二层剖面（包峰开始出现凹陷） | 神经网络一层层把它读回来 |
| 38.8–42 s | 第三层剖面：**两个尖峰分开** | — |
| 42–47.4 s | 线卷成一个 175 px 的大圆：光圈 | 不是超过光的极限，是把信息读出来 |
| 47.4–50.6 s | 圆填金，挖出两个孔 | — |
| 51.8–60 s | 落版 `TWO POINTS / 两点之间` | — |

## 科学上的分寸

这片子说的是**计算成像**，不是“AI 突破物理极限”，几点刻意保留：

- 艾里斑是**圆孔衍射**的结果，斑点尺寸 ≈ 1.22 λ/D（乘上成像距离），
  所以“焦点不是一个点”在物理上是正确的。
- 两点靠到瑞利判据以内，两个斑**确实会合成一团**——这是本片的核心视觉。
- 但**信息没有消失**：模糊是已知 PSF 与真实分布的卷积，在信噪比和先验允许时
  可以反解（反卷积 / 学习式重建）。片的说法是“把已有的信息读出来”，不是“变出细节”。
- 因此字幕最后落在“不是超过光的极限，是把信息读出来”。
  没有声称算法能无限超分辨，也没有把网络说成魔法。

## 技术复用

- 引擎是 `ATELIER LINEA` 复原版的通用化版本：新增 `spiral`（波前/汇聚）、`rings`（艾里斑）、
  `dots`（点光源）、`captions`（科普字幕）、`logo.holes`（多孔填金）。
- **同心环**新增“接缝错开”：每个环闭合后径向跳到下一环，再沿下一环走一小段，
  接缝绕着圈走，不会堆成一根竖线。
- 镜头仍是“平滑跟随笔尖 + 一次交还构图”，结尾 `settleTarget` 落在标志上。

## 已知取舍

- 三点五秒画三层剖面，靠字幕承担“这是神经网络”的解释；画面本身只说“信号被一层层修正”。
- 剖面图的横轴不是真实的空间坐标，是示意；不标刻度，避免假装定量。
- 两个点从“团”到“分开”是**同一条线再画一遍**（一笔画不能擦除），
  靠镜头与字幕把它读成“同一件事的三个阶段”。
- 60 秒里只有一次线转面，和原版节奏一致；没有做逐像素对齐（本片无参考片）。
