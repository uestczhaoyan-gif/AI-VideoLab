# ONE LIFE · 一生，一笔

82 秒一笔画叙事短片：一个人从出生的一团卷曲，到风筝、书本、台阶、门口、山顶的旗，
再到坠落与裂缝、打结的那些年、慢慢松开、一株花，最后画成一个圆，
**镜头退开——原来这一整幅画，就是那条线。**

## 为什么这样选形体

人生不能画人。一笔画能画的是**空间与物件**，所以每一段人生用一个能被线条认出来的东西代替，
并且让“上一个的尾”变成“下一个的头”：

| 时间 | 形体 | 含义 | 字幕 |
| --- | --- | --- | --- |
| 1.0–5.7 | 一团卷曲（螺线） | 出生 | 一开始，只是一团卷曲 |
| 6.3–13.1 | 菱形风筝（升线 + 落线） | 童年：被风托起来 | 风把线拉高——那是童年 |
| 13.1–17.0 | 一本打开的书 | 求学 | 书要一页一页读 |
| 17.0–21.2 | 六级台阶 | 一步一步往上 | 台阶一步一步上 |
| 21.2–23.7 | 上方的门框 | 机会 / 阶段的门 | 门口有过光 |
| 23.7–28.8 | 山脊与一面旗 | 成就 | 山顶插过一面旗 |
| 28.8–32.3 | 陡降 + 锯齿裂缝 | 失败 | 也摔过，摔出一道裂缝 |
| 32.3–47.0 | 向内绕紧、再反向松开的两条螺线 | 心结的那些年 | 心打成结的那些年 |
| 47.0–51.2 | 一段平静的波 | 和解：线自己松开了 | 后来，线自己松开了 |
| 51.2–55.7 | 茎 + 两片叶 | 只做喜欢的事 | 剩下的时间，只做喜欢的事 |
| 55.7–65.8 | 五片花瓣 | 花开 | — |
| 65.8–74.6 | 地平线 + 半径 180 的圆 | 结束：日落成圆 | 最后，画成一个圆 |
| 74.8–77.8 | 圆填金、圆心留一个小孔 | 圆满，圆心是自己 | — |
| 77.6–82 | 落版 + **镜头退开到全片** | 一生都在这条线上 | `ONE LIFE / 一生，一笔` |

**情绪靠垂直方向表达**：风筝、台阶、门、山一路向上；坠落、裂缝、心结一路向下；
松开之后是水平的一段波；结尾是一个圆。和解不是画一个新东西，而是**让线自己变平**。

**结尾为什么要退开**：这条线一辈子不能回头，所以最后只做一件事——把镜头交还给它自己。
退到 `z=0.55` 时，从出生那一小团卷曲到日落的那一圈，全部在同一帧里；观众第一次看见“全貌”，
而不是“又一个图形”。

## 发布文案（可直接用）

**主文案（约 120 字）**

> 我们都以为一生是一条直线。可回头看，它是从一个卷曲开始：被风拉高，被书压住，被台阶抬起；
> 也有过一道裂缝，和打成结的那些年。后来线自己松开了——一个人最后剩下的，
> 往往只是那件他喜欢做的小事。全片只有一条线，从第一个点到最后一个圆，
> 中间没有断开、没有擦除：**线不能回头，人也不能。**

**短版（标题下方/首句，约 40 字）**

> 一生，一笔。线不能回头，人也不能。

**一句话简介（平台简介栏）**

## 我自己的验收（先自己看一遍）

**成立的部分**

- 开场：一个亮点卷出一小团线，是全片最有“出生感”的两秒。
- 风筝：菱形 + 一根升线一根落线，干净、准确，是全片最像“童年”的一格。
- 台阶：六级台阶是全片识别度最高的一段，几乎不需要字幕。
- 心结：两条反向螺线叠在一起，第一次让这条线看起来“有情绪”，也是节奏最慢的地方。
- 结尾：花 → 地平线 → 圆 → 填金 → **退开**，四步收得住；退开后全片第一次成为“一幅画”。

**不成立 / 勉强的地方（下一版要修）**

1. **山顶与旗**读起来更像“帐篷 + 一根杆”：旗太小，山脊太规整。
2. **“坠落”没有坠落感**：镜头跟着笔尖走，线往下镜头也往下。要修得给引擎加“镜头锁定”，
   让坠落的 1.5 秒里镜头停住、线自己往下掉。
3. **裂缝**单独看仍像闪电，靠字幕才稳。
4. **花**的叶子与茎在小尺寸下会缠在一起。
5. 过渡帧不讲究：跟拍镜头在“从一个物体走到下一个”时会把前一个的顶部切掉
   （11.7 s 风筝只剩半只）。这是跟拍模型的固有代价。

- 响度 −14.0 LUFS、真峰值 −1.4 dBTP；渲染 1865 s（0.73 s/帧，含 4 次运动模糊采样）。
- 笔速约 151 px/s，心结段压到 110–125 px/s。
- 字幕严格串行：每句在下一句出现前 0.6 s 淡完（引擎 fade 0.45），已用脚本校验 `overlaps == []`。
- 结尾退开用 `camera.reveal`（引擎新增）：78.0–81.0 s 内把机位从太阳交还给全片，`z: 1.02 → 0.55`。
