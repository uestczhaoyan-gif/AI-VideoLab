# 一笔画制作方法（DeepseekDemo 版）

这份方法是把 `demo/mg-styles-15/demos/03-line-art/METHOD.md` 的要点，加上这次从零重写时
真正踩到的东西，整理成可以照着做的一版。按顺序做，每一步都有验收点。

## 0. 先定“观众依次看懂什么”，再定“线怎么连”

一笔画的失败基本都发生在这一步：几何连得上，但看不懂。
先写一句话的形体链，每个箭头都要能回答“上一形的哪个部位变成了下一形的哪个部位”：

```
种子（根环）→ 树苗（茎）→ 屋檐（茎顶折向右侧）→ 房子（檐下空间）
→ 天际线（基线隆起成楼）→ 山脊（基线整体抬起）→ 浪尖环（山脊末端绕环）
→ 标志（环 + 拱门）→ 字标
```

再给每个形安排**辨识时间**：新的形出现后，观众至少需要 0.3–0.6 s 才认得出，
所以形与形之间的转折要么减速，要么停顿。不要为了不断线而绕路、交叉、回描。

## 1. 先画最终构图（静止帧）

用 1920×1080 画布，把最后一帧当海报来画：主体在哪里、留白给谁、文字放哪。
一笔画的所有坐标都从这张图量出来，之后再决定“画的顺序”。

验收：把最终帧单独截出来，不看过程，它本身要成立。

## 2. 把线组织成四种“可画结构”

一条线要画出复杂画面，只需要四种局部结构：

| 结构 | 做法 | 用途 |
| --- | --- | --- |
| **叶/花瓣环** | 从茎上出去到尖端，再回到茎上稍高处，用“叶轴 + 半宽 + 法向偏移”生成两条贝塞尔 | 叶子、花、云、耳朵 |
| **板/檐双层** | 出到某点折返，沿平行线回到起点附近，形成有厚度的板 | 屋檐、台面、书页、地平线 |
| **凸起** | 从基线出发：正面墙上行 → 过顶 → 背面墙下行 → 回基线 → 前进 | 建筑、山峰、波浪、城市 |
| **自交环** | 行进中向内绕一圈再穿出，形成“浪尖”或“签名花” | 浪、结、签名、光晕 |

只要这四种够用，就不要发明第五种——新结构通常意味着观众会看丢笔尖。

## 3. 时间表：段末时刻 + 单调三次插值

- 给每一段一个 `start/end`，它们表示“这一段必须在什么时刻收笔”。
- 把 `(段末时刻, 累计弧长 / 总长)` 作为锚点，做单调三次（Fritsch–Carlson）插值。
  好处：C1 连续、不会过冲、转角自然减速、长线自然加速，没有分段缓动的速度跳变。
- 需要停顿的地方：给两段之间留一小段“同一弧长”的锚点，笔就停住。
- 复杂转角想更讲究，可以再叠加曲率减速；本版没有做，属于已知边界。

验收：任意时刻 `t` 求一次弧长，必须能稳定复现同一帧（渲染器按帧求值，不能有状态）。

## 4. 镜头：平滑跟随笔尖 + 一次退镜

```
cx = 平滑窗口内的笔尖 x + lead(t)/z
cy = 平滑后的笔尖 y + leadY/z
```

- **必须平滑**：笔尖在画环时会绕圈，直接跟随会让镜头猛甩。取 ±0.3 s 加权平均即可。
- `lead` 随段落变：开场让笔尖靠左（正在揭示），看城时让笔尖略偏右（前方留空）。
- `z` 单独一条曲线：特写 → 退开（看全城）→ 回到中等。一次“呼一口气”的退镜比一路匀速拉远高级。
- 结尾把镜头交还给整幅构图：`mix(跟随镜头, 定版镜头, ease)`。

## 5. 材质：三通道描边 + 笔尖光 + 颗粒

- 线：一条宽而淡的柔光 → 一条中等 → 一条实线 → 一丝更亮更细的高光。
- 线宽按 `1/z` 换算，保证屏幕上宽度恒定（不要跟着镜头变粗）。
- 笔尖：一个屏幕空间的小光斑（亮核 + 柔晕），收笔后淡出。
- 颗粒：一张 2048 颗粒图以 `screen` 低透明度叠加（深色背景上 `overlay` 几乎无效）。
- 背景：一个大半径径向渐变（中心亮、四角暗）就够了，不要叠太多层。

验收：把线的最亮处和最暗处取色，和参考片对比；线不应发白、不应发灰。

## 6. 线转面：整片只做一次

本片的做法（可直接复用）：

1. 离屏画布画金色圆面（线性渐变 + 上部柔光）。
2. `destination-out` 挖掉拱门（用 Path2D 的门洞形状），得到“圆面 - 门洞”。
3. `destination-in` 叠一个从**线落点**向外扩张的径向遮罩，做出“金色从落点长出来”的动势。
4. 把离屏结果贴回主画布，并在圆面外补一层极淡的金色柔光。
5. 填完之后跑一条**反向光脉冲**：沿整条路径从终点退回起点，把高潮和前面的轨迹连起来。

注意：不要在主画布上用 `destination-out`，会把背景和线条一起擦掉。

## 7. 文字

- 字标用高对比衬线（Cormorant Garamond），大写字距拉到 0.4–0.5 em，视觉上比字号更重要。
- 副标的短横线 + 光点用来把文字“钉”在画面里，不要做成装饰花纹。
- 出现方式：整体淡入即可，不要逐字打字机（会抢笔尖的注意力）。

## 8. 声音

- 三件套：**和声垫**（铺满、很轻）+ **事件音**（叶片、塔尖、填金）+ **笔触声**（跟绘制包络）。
- 和弦与旋律的时间点从 `cues.json` 读，画面改时间轴时声音跟着走，不写死秒数。
- 只在“线转面”处给一个清亮的金属重音，其余克制。
- 导出目标：-14 LUFS、真峰值 ≤ -1 dBTP（与上游成片同档）。

## 9. 验收清单

- [ ] 最终帧单独成立（不看过程）。
- [ ] 每个形有足够辨识时间；相邻形自然连接，没有交叉回描。
- [ ] 任意时刻可定位：`t=3.5` 重复两次渲染完全一致。
- [ ] 笔尖全过程在画面内（除刻意出画）。
- [ ] 只有一次线面转换；填金没有脏边、没有残影。
- [ ] 文字不裁切、字距正常、和圆面不打架。
- [ ] 解码核对：帧数 = 时长 × 帧率；分辨率与帧率正确。
- [ ] 响度与真峰值达标；笔触声与画面事件对齐（可用 `mgaudio.qc.hit_alignment`）。
- [ ] 正常速度看一遍——这是唯一能判断“高级感”的验收方式。

## 10. 已知边界

- 本版没有做曲率驱动的转角减速，也没有让配乐严格按屏幕笔尖速度变化。
- 镜头是“平滑跟随 + 曲线”，不是逐帧复原原片镜头。
- 逐像素一致需要原片的路径与镜头数据；本方法只能保证结构与观感。
