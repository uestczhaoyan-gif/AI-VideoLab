# 下一步：用这套东西做新片

`film/` 是**一部片**，不是模板库；但它把“一笔画”里所有会变的东西都放进了 `cues.json`，
所以做新片只需要换三样：形体链、路径、声音。

## 1. 起一部新片（30 分钟能出第一版）

```powershell
# 1. 复制一份场景
Copy-Item -Recurse film films\<新片名>
# 2. 改 films\<新片名>\cues.json：pieces 的 d/时间、logo、type、camera、music
# 3. 改 films\<新片名>\audio.py 的和弦与事件
# 4. 出静帧看节拍（先别看视频，静帧更容易看出形体辨识问题）
pwsh -ExecutionPolicy Bypass -File tools/render.ps1 -Mode stills -Times "1,3,5,7,9"
```

需要临时指向别的场景时，在 `tools/render.ps1` 里把 `$film` 换成 `films\<新片名>` 即可
（或加一个 `-Film` 参数，十分钟的改动）。

**顺序不要颠倒**：先定最终构图 → 再定形体链 → 再写路径 → 最后配声音。
先做声音会让人不自觉地把画面去凑音乐，一笔画最怕的就是节奏被外部牵着走。

## 2. 六个可以直接开做的题材（都符合“前后形相扣”）

| 题材 | 形体链 | 一句话 |
| --- | --- | --- |
| 咖啡 | 豆 → 芽 → 杯口 → 蒸汽 → 城市天际线 → 杯垫圆标 | 一颗豆到一座城 |
| 造书 | 笔尖 → 字行 → 纸页 → 书脊 → 书架 → 台灯圆光 | 书写变成建筑 |
| 地铁 | 轨道 → 隧道拱 → 车厢 → 线路图 → 换乘环 → 站徽 | 一条线穿过一座城 |
| 星轨 | 粒子 → 轨迹 → 山脊 → 银河弧 → 行星环 → 观星台圆顶 | 时间被画出来 |
| 微生物 | 细胞 → 鞭毛 → 分裂 → 菌落 → 培养皿圆边 → 显微目镜 | 生命的一笔 |
| 汉字 | “永”字 → 笔画延伸成屋檐 → 屋脊 → 山 → 印章圆 | 字即建筑 |

选择标准只有三条：**有天然的首尾相扣、有足够的负空间、结尾能收在一个圆或方里**。
不适合的题材：多主体叙事、需要人脸/写实材质、需要同时发生两件事。

## 3. 三个低成本变体

1. **竖屏 9:16**（抖音/小红书）：`window.DEMO` 改 1080×1920，`camera.lead` 改竖向，
   形体的“横向铺开”改成“纵向堆叠”，字标竖排。这一步会逼你重新想构图，但视觉语言不变。
2. **双色版**：主笔金 + 第二遍银线（同一条路径，用 `stroke-dasharray` 错开 3–5% 相位），
   得到“两种金属叠在一起”的质感，几乎没有额外工作量。
3. **循环版**：把结尾的基线右端用一条弧接回开头的左端，首尾各留 0.5 s，
   导出成可以无缝播放的 8 s 循环（适合做首页 banner / 视频号封面）。

## 4. 技术升级（按性价比排序）

| 升级 | 做法 | 收益 |
| --- | --- | --- |
| 曲率驱动速度 | 在采样点算曲率，`distance()` 里叠加减速权重 | 转角更“手工”，原片的高级感来源之一 |
| 笔尖速度 → 笔触声 | 渲染时导出 `timing.json`（每帧弧长），`audio.py` 读它算包络 | 声画严格同速，不再是分段包络 |
| 纸纹视差 | 颗粒层按 `cam.z` 轻微缩放/位移 | 画面有“被拍下来”的纵深 |
| 路径实时预演 | 一个只画 `stroke-dasharray` 的 HTML，滑动条改时间 | 改路径时不用等渲染 |
| 路径编辑器 | 小面板拖拽控制点，导出 `cues.json` | 从“写坐标”变成“摆形状” |

## 5. 风险清单

- **一笔画不是万能壳**：它天生只适合“一个东西长出另一个东西”的叙事。硬套会让线为了连通而绕路。
- **别叠加第二个线面转换**：整片只做一次填金，第二次会廉价。
- **别让镜头替叙事偷懒**：镜头可以引导注意力，但不能承担“看懂”。
- **字体必须真用上**：Cormorant 的对比度是这套视觉的一半；换成系统衬线会立刻掉档。
- **颗粒宁少勿多**：深色背景上颗粒一重就脏，`screen` 模式 0.05–0.10 已经够。
