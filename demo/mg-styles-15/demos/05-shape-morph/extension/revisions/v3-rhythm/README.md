# WANDER v3 · 节奏与整屏变化

回应用户对 v2 的意见：变化偏慢、节奏不明，主体只变形、背景变化不足。v3 在 10 秒内做八次短形变，每次约 0.48 秒、间隔 0.8 秒；每次形变同时带动全屏渐变、辅助图形与音乐重音。主体围绕画面中心，小范围、选择性地调整位置：鱼、叶、心等阶段稍作偏移，鸟到纸飞机、花到太阳则保持原位，并叠加幅度很小的漂浮。

顺序：水滴 → 鱼 → 飞鸟 → 纸飞机 → 叶片 → 花 → 太阳 → 心 → 水滴。稳定形态之间留短暂识别时间，片尾停在最后一个水滴并出现 WANDER 字标。新增背景装饰随形态淡入淡出，不切镜头掩盖转换。

## 当前源文件

- `src/film.js`、`src/cues.json`：轮廓、色彩和节拍。
- `src/audio.py`：更密集的打击节奏与转换提示音。
- `render.ps1`：生成 1080p 成片及轻量预览。
- [观看预览](preview.mp4) · [1080p 母版](video.mp4)：已按 v3 正确源码完整渲染。
- `keyframes/`：渲染目录，作为本地可再生成产物。

在 `demo/mg-styles-15` 执行：

```powershell
.\demos\05-shape-morph\extension\revisions\v3-rhythm\render.ps1
```

v3 成片于 2026-10-19 生成，标题下移避开主体，叶片阶段提高文字对比。第二次位置修订采用小幅、选择性偏移：部分转换保持原位，鱼、叶、心等阶段仅有轻微调整。原有 10 秒配乐未改变；最终画面使用本机 Edge 软件渲染并合成既有音轨。前一版 v2 的音视频及源码仍留在 `v2-sequence/`，不覆盖迭代记录。
