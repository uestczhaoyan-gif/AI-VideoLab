# WANDER v2 · 一滴，游过万象

用户认可鱼→鸟的转换和双翼修订，但担心长段落仍会僵硬。本版把关键转换研究扩展为 14 秒完整序列：水滴→鱼→双翼鸟→叶片→水滴。形态数量增加只是叙事选择，主要验证连续运动和跨段衔接。

## 衔接设计

水滴的主体延续为鱼身，尾鳍与背鳍逐渐长出；鱼身、眼睛和头部延续为鸟体，近翼从鳍展开，远翼新增生长。鸟体变成相似的叶片轮廓，翅膀收拢，眼睛退出，叶脉和叶柄出现；随后叶脉收去，叶尖保留为水滴尖端，主体旋转回直立。

位置使用跨段连续的三次曲线，形变时主体仍在移动；鸟转入叶片后由上扬改为飘落，再收束到片尾。保留识别时间，但不让每一形体都在原地停住再切换。

本片是想象叙事，不是水循环或生物演化说明。复杂孔洞与真实材料拓扑变化不在本轮验证范围内。

## 运行

从项目目录运行本文件夹的 `render.ps1`：先检查运动连接与任意时间重绘，再生成配乐、渲染 420 帧、解码验证和生成预览。需要既有共享依赖、DM Sans 与 HarmonyOS Sans 字体。新写轮廓、动作、布局和音乐，复用公共渲染器、字体与音色库，各自保留许可。

初版整片及两次关键转换研究均保留，不以新版覆盖失败证据。最终流畅度需用户观看，数值连续不自动等于审美通过。

## 本轮结果

完整解码通过：14 秒、1080p、30 fps、420 帧。已查看关键帧及十四格分镜，运动曲线连接与跳转重绘检查通过。音轨约 −16.0 LUFS、−4.9 dBFS；仍待用户正常速度观看与审听。
