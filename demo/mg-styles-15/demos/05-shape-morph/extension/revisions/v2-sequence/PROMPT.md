# v2 完整序列 brief

背景：初版 WANDER 被指出僵硬；鱼→鸟短研究的部件对应得到基本认可，随后缩小近翼并让后翼从肩部生长，用户同意继续，但提醒长时间播放可能缺乏流畅感。

目标：制作 14 秒、1080p、30 fps 完整段落，检验短研究能否扩展成连贯叙事。采用水滴→鱼→双翼鸟→叶片→水滴，主体保持可追踪，形态变化与位移／转向重叠，不靠停顿、切换背景或增加图标数量掩盖不自然的衔接。

| 转换 | 时间 | 承接关系 |
| --- | --- | --- |
| 水滴→鱼 | 1.2–2.8 秒 | 共同主体转为横向，尾鳍、背鳍和眼睛出现 |
| 鱼→鸟 | 3.4–5.6 秒 | 保留身体、头部、眼睛；近翼展开、后翼新增生长 |
| 鸟→叶片 | 6.7–8.8 秒 | 相似的身体弧线扩为叶片，翅膀收拢，叶脉与叶柄出现 |
| 叶片→水滴 | 9.5–11.3 秒 | 叶尖延续为水滴尖端，附属纹理退出，主体回转 |
| 收束 | 12.1–14 秒 | 水滴与 WANDER 字标形成结尾 |

关键帧检查后，修正片尾位置曲线的切线设置，避免倒数两个路径段的速度不一致；调整鸟阶段的水平位置，使其转为叶片前继续向前，而不是提前倒退。曲线连接检查与跳转重绘检查通过后再渲染。

本版未被用户验收，不声称“增加形态”本身解决了丝滑问题。此前接受的是短研究的方向，不能扩大解释为新增长段落已经通过。
