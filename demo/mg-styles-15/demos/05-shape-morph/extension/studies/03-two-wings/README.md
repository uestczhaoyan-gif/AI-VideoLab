# 03 · 双翼比例与生长

用户认为研究 02 的转换可以，但鸟翼过大、没有第二只翅膀，并指出转换中可以生长新部件。

本版保持原来身体、眼睛、移动与转向的连续对应，调整：

- 缩小近侧翅膀：翼尖目标由约 `(-150,-209)` 收至 `(-111,-145)`，收紧翼面轮廓。
- 在身体后方新增较窄、颜色较深的远侧翼；它在 2.05–3.60 秒从肩部平滑生长，随后与近翼轻微错相摆动。
- 近翼由鱼鳍延伸，远翼允许新增，不强迫全部形体一一对应。
- 前后翼分层绘制，身体遮挡远翼根部，保持附着与深度关系。
