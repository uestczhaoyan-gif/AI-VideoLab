# 02 · 鱼鳍展开为羽翼：关键转换研究

用户指出 WANDER 初版僵硬，缺少原作利用形状相似性的衔接。本次只验证“鱼→鸟”一段，6 秒、1080p、30 fps、无配乐；不是新版整片，也不代表已经达到原版完成度。

[观看短预览](preview.mp4)。`film.js` 与 `index.html` 是该研究的独立源码，初版整片保留在上级目录。

## 相比初版改变了什么

- 先重新设计鱼和鸟，使身体、头部和眼睛保持对应；不再把横向鱼形变成正面海鸥图标。
- 将轮廓拆为身体、尾部、背鳍／翅膀，每个贝塞尔段有明确的对应角色，删除依赖全轮廓最小距离匹配的做法。
- 鱼鳍沿原位置展开为鸟翼，鱼尾收拢为鸟尾，头部逐渐长出鸟喙；眼睛跟随头部而不消失重现。
- 主体沿一条连续方向移动和上扬，形变过程中保持前进，不先停稳再更换图标。
- 本次先移除配乐对节奏感的辅助，单独观看形状与动作；通过后再扩展到完整叙事。

这些是视觉形态的设计对应，不是生物学结构演化说明。已检查开始、中间及结束关键帧，最终衔接是否自然仍由用户正常速度观看判断。
