# 创作要求与分镜

用户目标：用已复现并完成过迁移的等轴动画方法，演示芯片运行中的一个流程。选择“一条加法指令怎样执行”，18 秒，1080p，30 fps，配乐和事件音效，无配音。

制作芯片功能模块的等轴微缩模型；用清晰可读的数字标记追踪操作数和结果，不以没有含义的光点代替解释。采用蓝绿、暖白与金色配色，保持柔和光影。模块包括指令存储器、译码／控制、寄存器组、ALU；标明是简化示意，非真实布局或周期比例。

画面显示 `ADD x3, x1, x2`，源寄存器初始为 3、5，目的寄存器初始为 0。读取不改变源值，ALU 先得到 8，结果随后移动到寄存器组，到达后才把 x3 更新为 8。标题与模块名始终能读，结尾保留结果观察时间。

| 时间 | 内容 |
| --- | --- |
| 0–4 秒 | 建立空间，指令从存储器传向译码模块 |
| 4–6.5 秒 | 明确加法、两个源寄存器和目标寄存器 |
| 6.5–10 秒 | 数字 3、5 沿两条路径进入 ALU，源值保留 |
| 10–13 秒 | 显示 3+5=8，x3 仍为 0 |
| 13–15 秒 | 结果 8 沿回写路径返回寄存器组 |
| 15–18 秒 | x3 更新为 8，保持结果和全局构图 |
