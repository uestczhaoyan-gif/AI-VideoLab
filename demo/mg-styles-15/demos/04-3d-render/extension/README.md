## 修改机制

- 76 个稀疏单元改为 1,080 个六角紧密排列单元，中心距 0.29、直径 0.278。
- 删除四圈独立定时振荡，按每个单元到中心的真实距离计算共同波面；第一道波以 1.6 单位／秒向外推进，0.9 秒后跟随较弱的第二道波。
- 波峰使用平滑余弦轮廓，宽度覆盖多个单元；底部固定、顶部连续升降，避免整颗物体漂浮弹跳。
- 相机固定，统一阵列材质，减少环形分色和镜头变化对波动辨识的干扰。

这是风格化形变，不是体积守恒软体或真实波动方程求解。

## 源码与检查

`src/wave.json` 为公共参数；`src/radial_wave.py` 是 Blender 使用的阵列与波面函数，`src/scene.py` 已改接此函数；`motion-preview/film.js` 使用相同参数生成快速预览。

35 个时间／半径样本中，浏览器与 Python 波面数值在 1e-10 容差内一致，单元数量一致。预冲击静止、微小时间变化的连续性已检查；2.6 秒和 4.2 秒跳转重绘画面哈希一致。用户已观看并认可运动观感；数值一致只作为浏览器／Blender 迁移的工程检查依据。
