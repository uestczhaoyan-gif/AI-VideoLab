# SUNGRID · 创作 brief 与复用 Prompt

本记录对应本次模型阅读上游代码后的设计与实施，不是独立盲测的单次输入。主题由助手在用户授权“总结后直接拓展”后选择；原版复现已获得用户认可。

## 本次创作要求

制作一支 12 秒、1920×1080、30 fps 的等轴微缩动画，主题“一束阳光，点亮一座小镇”。用同一个连续空间展示太阳能板采集、电池储存、能量传递与住宅亮起。造型圆润、光影柔和，以苔绿、奶油白、陶土红与阳光金形成温暖的微型世界。

对象先错峰出现，再通过清晰的能量路径与电池状态变化讲述过程。文字简短，视觉变化承担主要信息。结尾保留完整构图和阅读时间。声音使用重新编排的轻打击旋律、和弦与事件音效，和共用事件表同步。

可以复用原项目的离线渲染基础设施、累计渲染器和音色库；必须重写场景布局、几何组合、时间更新和音乐编排。画面是能量流向示意，不出现未经计算的性能数据，也不把移动光点解释成真实电荷速度。

## 可迁移 Prompt 骨架

“以【视觉风格】制作【时长】的【概念】动画。观众需要理解【状态变化／因果关系】。用【必要对象】在一个可追踪的空间中呈现【核心事件】，先确保关系正确和注意力清晰，再自由设计造型、色彩、镜头和声音。提供源码、事件表、渲染结果与检查记录；说明复用内容与新写内容。”

这是本例总结后的方法草案，还没有通过跨模型对照试验。它不保证一句话或一次执行达到相同效果。
