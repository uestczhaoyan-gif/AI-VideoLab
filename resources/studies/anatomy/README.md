## 为什么加入

项目把技术概念构造成可操作的机器、仪器或物体，用部件、连接、动作与实时读数解释机制。主要产物为交互式 HTML、SVG 或 React 组件，可选 WebGL 效果和试验性 3D 运动。

它与用户提到的 Anatomy 相匹配，但“解释任意科学概念”需要收窄为待验证目标：作者明确更擅长可构造成机器或机制的对象，不是通用图表库，也不主打人物或精确地图。交互图解与完整 MP4 制作是两个不同交付范围。
