## 1. 当前能用什么

| 你的目标 | 当前操作与结果 |

## 2. 启动与关闭

### 2.0 方式一：CLI 对话制作（推荐）

当前电脑已安装 Pi。在 Windows Terminal 或 PowerShell 中运行：

```powershell
Set-Location "C:\Users\86131\Desktop\VideoLab"
npm.cmd run cli
```

命令等价于在仓库根目录执行 `pi @docs/library/CREATE_VIDEO.md`，把 [制作启动任务](library/CREATE_VIDEO.md) 作为首轮输入。它不启动网页、不新建模型客户端、不改已有账号或模型配置；新会话的实际模型以 Pi 启动状态为准。此模式需在交互终端运行，不要把输入输出重定向，否则 Pi 可能进入单次输出模式。

然后直接描述主题。例如：

```text
我想做一段介绍伴随法的视频，面向懂 Maxwell 方程的研究生。
需要核心公式解释为什么两次场求解能得到大量参数的梯度。
时长可在 60–90 秒，中文配音和字幕，风格请根据内容帮我选。
优先使用当前助手和本地工具。
```

助手一般用 1–3 轮短问答补齐关键缺项，再选主方案并制作；已有信息不重复问，不要求你填写引擎或多组 API。建议明确“观众基础／看完要懂什么／公式深度”，这些会影响讲稿、风格、镜头与时长。已授权、条件齐备的制作可继续，不需要为每个可逆步骤确认。

如果已经在当前 Pi 或其他 AI 编程 CLI 会话中，直接说“读取 `docs/library/CREATE_VIDEO.md`，按这份流程开始制作”即可，不必再启动嵌套会话。退出 Pi 后可在同一目录用 `pi --continue` 继续最近会话；这会沿用原上下文，不重新注入新片问卷。恢复哪个任务应核对会话内容。

其他 CLI 不要求安装 Pi，只需能读取本目录并执行工具，采用同一份启动任务即可。新电脑缺少 Pi 时，`npm run cli` 会报告命令不存在；不会自动安装、登录或索取密钥。使用你已有的助手，或按所选 CLI 自身文档完成配置。

### 2.1 方式二：Web 浏览与选型（可选）

本机已经有 Node.js `v24.14.0`、npm `11.9.0` 和工作台依赖，可以直接启动。

1. 打开 Windows Terminal 或 PowerShell。
2. 复制执行下面两行：

```powershell
Set-Location "C:\Users\86131\Desktop\VideoLab"
npm.cmd run web
```

3. 看到类似下面的信息后，保持这个终端窗口开启：

```text
VideoLab: http://127.0.0.1:4317
```

4. 用 Edge 或 Chrome 打开 <http://127.0.0.1:4317>。建议把这个地址加入收藏夹，之后固定使用同一浏览器、同一地址。

服务不会自动打开浏览器。它只监听本机回环地址，主要供这台电脑使用。`npm.cmd run web` 与原有 `npm.cmd run dev` 启动相同服务，下文保留的 `dev` 命令仍然有效。

本手册统一使用 `npm.cmd`，这样可以避免 PowerShell 因 `npm.ps1` 的脚本执行策略而拦截 npm；它执行的仍是同一组项目命令。

### 2.2 关闭与下次使用

先保存或导出需要保留的方案，再回到运行服务的终端按 `Ctrl+C`。下次使用时重新运行上面的两行命令，并打开同一网址。

关闭服务不会删除已经保存在浏览器中的方案。尚未保存的表单内容不会自动备份，刷新网页也会丢失这部分编辑。

### 2.3 新电脑或依赖缺失时

需要 Node.js **22 或以上版本**，安装 Node.js 时通常会同时安装 npm。普通浏览工作台不需要 Python、FFmpeg、Blender 或 API Key。

```powershell
Set-Location "C:\Users\86131\Desktop\VideoLab"
node --version
npm.cmd --version
npm.cmd ci --ignore-scripts
npm.cmd run catalog:check
npm.cmd run dev
```

`npm.cmd ci --ignore-scripts` 按根目录锁文件安装依赖，通常需要联网；不必每次启动都执行。已有依赖和本地资料时，工作台浏览、选型和导出可离线使用；原始来源外链仍需联网。

如果换了项目位置，请修改 `Set-Location` 后面的路径。无需先执行 `catalog:import`，随仓库提供的索引即可启动。

### 2.4 默认端口被占用时

如果终端提示 `Port 4317 occupied`，可以改用 4318：

```powershell
$env:PORT = "4318"
npm.cmd run dev
```

然后访问 <http://127.0.0.1:4318>。停止服务后，如需在这个 PowerShell 窗口恢复默认端口：

```powershell
Remove-Item Env:PORT
npm.cmd run dev
```

**换端口会进入另一份浏览器存储。** 在 4317 保存的方案不会自动出现在 4318；返回原地址仍可读取原来的记录。

## 3. 第一次使用：完成一份制作方案

下面用“30 秒解释种子发芽”为例，走完目前可用的全过程。这个例子用于整理制作任务；目录中的示例条目只是参考，不会随表单自动变化。

1. 打开工作台，在“模板库”搜索 `种子` 或 `平面矢量`，找到 MG 集合中的“平面矢量”条目。
2. 点击条目封面或名称打开详情。当前条目以参考图／Prompt 为主，可能显示“尚无预览”或“本机预览文件缺失”；这不影响继续选型。
3. 查看“本地验证”“证据状态”“时间规格”“谱系”“许可与使用”“参数与运行条件”，再点击“采用此模板”。页面会进入“制作方案”。
4. 参照下表填写需求：

| 字段 | 示例填写 |
| --- | --- |
| 主题 / 文案 | 用 30 秒向中学生解释种子在水分、适宜温度和氧气条件下萌发，画面表现吸水、胚根伸出和幼苗生长。 |
| 视频用途 | 知识讲解 |
| 时长 · 秒 | 30 |
| 画幅 / 分辨率 / 帧率 | 横屏 16:9 / 1080p / 30 fps |
| 语言 | 中文 |
| 配音 / BGM | 初次演练先选“无配音”“无 BGM” |
| 需要字幕 | 勾选 |
| 预算上限 / 使用场景 | 预算可留空；个人 / 研究 |
| 附加要求 | 面向中学生；保留萌发条件的科学准确性；避免把所有种子的萌发都表现成必须见光。 |

5. 在右侧“候选流程”中明确选择“科普与数据解释”。采用模板时系统会根据用途和关联关系选择候选，仍需你检查这一项。
6. 滚动到“阶段路由”，切换“平民版”和“高玩版”，比较阶段分工。两档保留相同的视频规格，当前模型和费用仍显示待配置／未知。
7. 继续向下看“确认门与 QA 契约”：三处人工确认是需求 / Brief、风格帧 / 样片、导出前；QA 清单分技术、内容、视觉、声音、完整观看、用户采用六类。工作台只展示契约，不替你签字，`NOT CHECKED` 不算通过。实际确认与检查结果在 CLI 或项目工具中记录。
8. 点击页面上方“保存方案”。看到“方案已保存到当前浏览器”后，进入左侧“已存方案”，确认这份草案存在，并点击“打开”验证可以重开。
9. 在“制作方案”底部，分别点击“JSON”和“制作任务包”，保存两份下载文件。通常文件名为 `videolab-plan.json`、`videolab-plan.md`；浏览器可能为重复下载增加编号。导出内容包含确认门、文档引用与 QA 状态。

完成后的产物是一份浏览器内草案，以及两份用于备份和交接的文件。接下来按第 7 节把它交给制作工具或 AI 助手。

## 4. 模板库：查找、预览、收藏与对比

### 4.1 搜索与筛选

搜索框支持名称、风格、上游编号以及索引中已有的关键词，例如“一笔画”“白板”“数据”。空格分开的多个词需要同时匹配；它不会对全部原始 Prompt 做全文搜索，也不是语义搜索。

| 控件 | 怎么使用 |
| --- | --- |
| 全部集合 | 选择 Lemo、MG、Prompt 或其他工具；左侧资料集合也能切换 |
| 全部类型 | “参考”用于看方向；“Prompt”有提示词或说明；“工程”登记了工程路径 |
| 全部用途 | 只显示已标注相应用途的条目，未标注的可能被排除 |
| 全部风格 | 按目录中的风格类别筛选 |
| 有本机预览 | 只显示本机确实存在预览文件的条目 |
| 商用已核查 | 只显示许可状态已明确允许的条目；本次检查为 0 条 |
| 重置筛选 | 清除关键词、集合、类型、用途、风格和勾选条件，也退出收藏筛选 |

每页最多显示 24 个条目，可用页面底部“上一页／下一页”翻页。筛选条件会叠加；切换左侧集合不会自动清除其他条件。如果意外得到空结果，先重置筛选，再从一个关键词开始。

### 4.2 读懂详情页

点击封面或名称打开详情，重点看：

- **原始文件**：本机是否已取得对应的 Prompt 或说明；缺失时需要按来源固定版本恢复。
- **工程范围**：有工程路径表示登记了一个目录，仍需核对依赖、素材和入口。
- **本地验证**：区分仅索引、源码初读、技术检查和既有案例反馈。
- **参数与运行条件**：未逐项登记时，表单中的时长、分辨率等只是需求，不表示该模板已经支持。
- **许可与使用**：核对工程、字体、音乐和图像等各部分；根目录 MIT 许可不自动覆盖所有第三方资料。

“原始文件”和“来源笔记”会在工作台内以纯文本显示 Markdown，出现 `#`、链接语法等是正常的；“原始来源”会打开外部网页。工作台不提供上游 HTML 模板的直接运行预览。

“尚无预览”表示索引没有登记媒体；“本机预览文件缺失”表示已登记媒体，但当前电脑找不到对应文件。两者都不影响继续查看条目信息。

### 4.3 收藏与比较

点击条目上的书签图标可收藏或取消收藏，再用“收藏”切换查看。收藏仍会叠加其他筛选条件。

点击对比图标可加入对比列表，最多 3 个；点击底部“比较条目”并排查看效果、类型、取得情况和许可。点击同一条目的对比图标可移除，也可以点击“清空”。对比列表不会在刷新后保存。

## 5. 流程库与制作需求怎么选

### 5.1 三条候选流程

左侧“流程库”展示每条路线的阶段、输入条件、当前缺口和来源。点击“采用此流程”会带入制作方案；之后检查右侧所选模板是否合适。

| 流程 | 适合的需求 | 优先准备 |
| --- | --- | --- |
| 代码动效短片 | 短动效、产品视觉、图形叙事等 | 准确文案、目标效果、时长画幅、模板及素材 |
| 科普与数据解释 | 知识讲解、机制图解、数据报告 | 事实或数据出处、单位、要解释的关系 |
| 真实产品与素材包装 | 实际产品介绍、功能演示 | 真实截图或录屏、功能事实、素材与声音 |

三条路线当前都是草案，尚未接执行适配。“按用途匹配 · 候选”使用用途标签和少量预设关键词排序，不能理解整篇文案或保证成片质量；主题的具体要求仍需要制作时人工核对。

### 5.2 表单填写规则

| 字段 | 当前支持与注意事项 |
| --- | --- |
| 主题 / 文案 | 必填，最多 2000 字；长稿可把摘要填在这里，再在附加要求中注明单独稿件的位置 |
| 视频用途 | 知识讲解、产品介绍、数据报告、叙事短片、短动效 |
| 时长 | 5–3600 秒；长片能力仍取决于实际采用的工具 |
| 画幅 | 16:9、9:16、1:1、3:4 |
| 分辨率 / 帧率 | 720p、1080p、2160p；24、30、60 fps |
| 语言 | 中文或 English |
| 配音 | 无配音、AI 配音、自带音频；选择后只是登记需求，服务或文件待提供 |
| BGM | 无 BGM、授权曲库、自带音乐；尚无选曲、上传或自动合成功能 |
| 需要字幕 | 登记字幕需求，当前不会自动生成字幕文件 |
| 预算上限 | 可留空；填写时为 0.01–100000，币种 CNY 或 USD；不能填 0 表示免费 |
| 使用场景 | 个人 / 研究或商业发布；商业用途会显示相应许可缺口 |
| 附加要求 | 最多 3000 字；建议填受众、事实出处、已有素材、参考、音色、等待时间和不可改动内容 |

选“自带音频／自带音乐”后，在附加要求中记录本机文件位置，并在后续交接时提供文件。该页面没有上传入口，也没有读取这些文件。

首次进入时默认选择“种子长成花园”，规格为 30 秒、16:9、1080p、30 fps、中文、需要字幕、无配音、无 BGM、个人 / 研究。默认值需要按你的任务检查。

### 5.3 高玩版和平民版的含义

高玩版倾向于把可靠的候选用于创意、实现和检查；平民版倾向于复用成熟模板，把较强候选集中在难点和返修。表格列出的都是阶段策略。

当前尚无可直接采用的准确模型配置、价格或两档质量对照实测。因此：

- 切换档位不会调用模型或产生模型费用。
- “预计费用：未知”不等于免费，填写的预算也不等于预计报价。
- 两档保持同一份时长、画幅、分辨率、声音等要求；最终效果仍需实际制作验证。

## 6. 保存、重开与导出

### 6.1 浏览器保存

“保存方案”把当前需求和所选模板／流程版本写入当前浏览器的本地存储。左侧“已存方案”可打开、导出 JSON 或删除记录；删除时会要求确认。

**每次点击保存都会新增一份方案，不会覆盖旧方案。** 打开旧方案后修改并保存，也会得到新记录。重要方案建议同时下载 JSON 和制作任务包。

需要记住的行为：

- 没有自动保存；导出文件也不会自动新增“已存方案”记录。
- 在同一个页面内切换导航会保留当前编辑；刷新或关闭页面会丢失尚未保存的编辑。
- “制作方案”按钮用于进入编辑页，不会自动清空前一份内容；开始新任务时逐项检查并替换。
- 退出浏览器后，正常保存在本地存储中的记录通常仍在；无痕窗口或清理站点数据会影响保存。

### 6.2 保存在哪里

方案和收藏保存于当前浏览器配置文件、当前网址的 `localStorage`，没有写入仓库，也没有服务端数据库。

以下情况会看不到原记录：换浏览器或浏览器用户、换端口、把 `127.0.0.1` 改成 `localhost`、使用无痕窗口、清理该站点数据。关闭再启动同一地址的服务本身不会清空记录。

复制 VideoLab 文件夹或提交 Git **不会带走浏览器内方案**。目前也不支持跨机器同步或从 JSON 文件导入方案；JSON 可保留完整结构供人工或 AI 读取，在新浏览器中仍需据此重填。

### 6.3 两种导出怎么用

| 按钮 | 文件 | 用途 |
| --- | --- | --- |
| JSON | `videolab-plan.json` | 保存结构化需求、ID、版本、来源、阶段、预算、缺口，以及 `gates`／`documents`／`records.checks`（确认门、文档槽与 QA 状态），便于程序或 AI 读取 |
| 制作任务包 | `videolab-plan.md` | 便于人阅读、复制和交给 AI 助手执行后续制作；含确认门、项目文档引用与 QA 清单 |
| 已存方案中的下载图标 | `videolab-<方案ID>.json` | 导出当时保存的版本，包括目前已不能重开的旧版本 |

下载位置由浏览器设置决定，可按 `Ctrl+J` 查找。建议把文件重命名为带主题和版本的名字，例如 `种子发芽-30秒-v1.json` 与 `种子发芽-30秒-v1.md`。

导出的是**引用型任务包**：包含制作要求、模板和流程版本、原始路径、来源、阶段交付、确认门、QA 状态以及待解决事项；不打包媒体、完整源码、字体、原始 Prompt 正文或密钥。接收者需要能访问同一仓库及对应本地资料，或者按固定来源恢复。

### 6.4 模板或流程版本变化

旧方案会保留原版本。如果模板或流程的 revision 已变化，打开时会提示重新选择，不会静默替换旧引用。先从“已存方案”导出旧 JSON，再根据新版本检查需求并另存。

## 7. 导出后怎样真正制作视频

CLI 路线不需要先导出任务包：可直接从第 2.0 节开始。若已在 Web 选好方案，把制作任务包交给能够读取项目文件的 AI 编程助手或相应工具，在工作台之外完成执行。当前没有 Web 与 CLI 项目的双向同步。

推荐流程：

1. 同时准备 Markdown 任务包和 JSON；把长稿、事实来源、已有素材路径补齐。
2. 让助手读取任务包引用的 Prompt、案例 README 和来源笔记，确认哪些内容可直接复用。
3. 根据任务包中的“执行前缺口”，补齐模型或工具、依赖、素材、声音与授权。选了 AI 配音并不代表已经有可用 TTS 服务。
4. 先做 5–15 秒代表片段或少量关键帧，确认内容、风格和运动，再制作全片。
5. 输出成片及可编辑工程，检查实际规格、字幕、声音和素材来源；完整观看、试听后再记录采用结果。

可以把下面的交接文字连同任务包发给助手；把示例文件路径替换为实际位置：

```text
请在 C:\Users\86131\Desktop\VideoLab 中协助制作这份任务包描述的视频。
先读 AGENTS.md、PROJECT.md，以及我提供的制作任务包 Markdown 和 JSON。

以任务包中的需求、模板／流程版本和附加要求为准，按引用路径读取相关资料。
先核查输入、依赖与执行前缺口，优先复用已有工程、渲染和检查工具。
在独立目录保存本次制作，保留原案例与旧方案。
先完成一个代表片段供我检查，再推进完整视频。

不要把“参考预览存在”当作“当前任务已验证可执行”。
需要付费模型调用、外部上传或发布时，先说明具体操作与费用，再等我确认。
完成时交付视频、可编辑工程、实际使用的输入与版本、素材说明和检查结果。
```

任务包中的“交付与验证”列的是后续应产出的内容，不代表导出时已经生成了这些文件。制作方法可进一步参考 [Prompt 指南](library/PROMPTS.md) 和 [流程说明](library/WORKFLOW.md)。

### 9.2 缺资料时怎么恢复

索引与实际媒体是分开保存的。新机器可能仍能显示 408 个条目，但看不到部分预览或原始文件。

1. 在详情中确定来源和缺失路径。
2. 打开对应来源笔记，再按 [catalog 恢复缓存说明](../catalog/README.md#恢复缓存) 获取固定版本。
3. 主要缓存位置为 CAP 的 `docs/theory/_sources/code-animation-prompts/`、Lemo 的 `resources/lemo-opuscar/source/`、MG 的 `resources/mg-styles-15/source/`。
4. 恢复完成后，如需重新构建索引，在根目录执行：

```powershell
npm.cmd run catalog:import
npm.cmd run catalog:check
```

导入会更新 `catalog/` 中的索引及相关报告，不会自动下载上游文件。输入指纹不符时应核对版本和本地修改，不要直接删除指纹记录来绕过检查。

只补回相同路径的预览文件时，刷新网页即可重新检查存在状态；如果修改或重新导入了 catalog 内容，应停止并重启服务，因为服务启动时才加载索引。

### 9.3 常用检查命令

都在项目根目录执行；普通日常使用不必每次运行全套检查。

```powershell
npm.cmd run catalog:check
npm.cmd test
npm.cmd run docs:check
npm.cmd run test:ui
npm.cmd run loop:smoke
```

- `catalog:check` 检查索引结构、引用、路径和能力标记。
- `test` 运行目录、方案逻辑、项目契约（确认门／文档／QA）、服务和归档相关测试。
- `docs:check` 检查 Markdown 本地文件链接，不核验外链和标题锚点；归档历史链接单独报告。
- `test:ui` 使用已安装浏览器检查页面操作、布局与契约面板；报告在 `.tmp/workbench-verification/`，不会自动安装浏览器。
- `loop:smoke` 用本地确定性动画跑一次 Brief→渲染→编码→QA 的最小闭环，需要浏览器与 ffmpeg；产物在 `.tmp/loop/`。它不是风格 demo，也不替代真实成片的视听验收。

找不到测试浏览器时，可指定实际可执行文件路径：

```powershell
$env:VIDEOLAB_BROWSER = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
npm.cmd run test:ui
```

契约或 QA 规则改动后，先运行 `npm.cmd run project:schema` 重新生成校验器，再跑测试与闭环。

## 10. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `pi` 命令不存在 | `npm run cli` 复用已有 Pi，不自动安装；可让其他已配置助手读取 `docs/library/CREATE_VIDEO.md` |
| 想使用核心公式但网页没有专用选项 | CLI 直接说明受众基础、公式深度与前置知识；Web 目前写入“附加要求”，专用字段尚未实现 |
| `node` 或 `npm.cmd` 无法识别 | 安装 Node.js 22+，重新打开终端，再检查版本 |
| PowerShell 提示 `npm.ps1` 禁止运行 | 使用本文的 `npm.cmd` 命令，无需为启动工作台修改全局执行策略 |
| 提示找不到 `package.json` 或 `Missing script: dev` | 先用 `Set-Location` 回到 VideoLab 根目录；子目录可能有不同项目 |
| `Cannot find package 'ajv'` 等依赖错误 | 在根目录运行 `npm.cmd ci --ignore-scripts` 后重试 |
| 浏览器无法访问 | 确认终端服务仍在运行，地址与终端输出一致，使用 `http://` |
| 端口占用 | 按第 2.4 节设置其他 `PORT`；新端口的浏览器记录独立 |
| 双击 `index.html` 后不能用 | 工作台依赖本地服务，请通过 `npm.cmd run dev` 和 HTTP 地址访问 |
| 页面提示“目录读取失败” | 查看运行服务的终端错误，执行 `catalog:check`，修正问题后重启并刷新 |
| 搜索不到预期条目 | 重置筛选，尝试更短关键词；用途只筛已标注条目，多词搜索要求同时匹配 |
| 勾选“商用已核查”后无结果 | 当前没有已完成商用核查的条目，这是实际状态；取消勾选可继续研究参考 |
| 预览或原始文件缺失 | 按来源固定版本恢复缓存；重新安装 npm 依赖不会补齐这些媒体 |
| 视频没有声音 | 预览默认静音，先取消静音；是否有有效音轨仍取决于原视频 |
| 改了文案，右侧参考图没有变化 | 右侧仍是所选模板的参考预览；当前没有实时生成或渲染功能 |
| 找不到“生成”按钮 | 当前只提供方案与任务包，实际制作按第 7 节交接 |
| 保存或导出没有成功 | 检查必填主题、时长范围、预算；留意浏览器存储或下载提示 |
| 提示浏览器存储不可用 | 先导出文件保留编辑，再检查浏览器隐私／存储设置；导出文件目前不能直接导入 |
| 重开后找不到方案 | 检查原浏览器用户、地址和端口；未保存或已清除站点数据的记录无法靠重启服务恢复 |
| 提示模板或流程版本变化 | 从“已存方案”先导出旧 JSON，再重新选择并另存 |
| 原始文档显示 Markdown 符号 | 当前按纯文本展示，这是正常行为 |
| 更改 catalog 后网页仍是旧内容 | 停止并重启 Node 服务，再刷新页面 |
