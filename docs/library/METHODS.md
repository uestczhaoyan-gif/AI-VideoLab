# 分类与候选方法

本表来自现有资料的归纳。`M01`–`M16` 是便于检索的组合标签，包含技术基础、专门表现手法与完整流程；它们可以重叠，不是互斥的模型能力分类，也不代表 16 条已验证流水线。

## 分类维度

同一个视频同时有用途、形式、风格和技术路线。先明确观众要得到什么，再选表达方式与工具。

| 维度 | 例子 | 后续界面如何使用 |
| --- | --- | --- |
| 用途 `purpose` | 产品介绍、操作教程、知识解释、数据报告、广告、叙事短片、音乐视觉、数字人口播 | 主选择项，可多选 |
| 表现形式 `form` | 连续对象变化、白板绘制、动态图表、录屏标注、角色表演、分镜剪辑、动态文字 | 决定镜头／分段结构 |
| 视觉风格 `style` | 平面矢量、一笔画、水彩、拼贴、像素、等轴、写实、玻璃材质 | 从 [风格索引](STYLES.md) 选择，不直接决定引擎 |
| 技术路线 `route` | 浏览器代码、Manim、Remotion、Blender、真实素材剪辑、图像／视频生成、混合 | 过滤依赖与输出能力 |
| 自动化 `automation` | 人工操作、Agent 辅助、脚本生成、有可调用 API | 区分自动准备与自动执行 |
| 资源条件 `resources` | CPU／GPU、显存、可用 API、已有素材、可用时间、预算 | 排除当前无法执行的候选 |
| 证据 `validation` | 仅线索、文档已读、源码已读、技术通过、已观看、已有迁移案例 | 展示可用程度与不确定项 |

例如“科普 + 一笔画 + 浏览器代码”和“产品广告 + 一笔画 + 浏览器代码”可以共享基础设施；同一个科普主题也可能使用 Manim、真实录像或混合剪辑。

## 16 个起始方法标签

成本栏描述主要消耗，未核查当前服务报价。模型费、生成费、渲染时间和人工返修分别记录，不能以“代码开源”推断免费成片。

| ID | 方法与适用任务 | 主要输入 → 产物 | 已有资料与实际边界 | 成本与主要限制 |
| --- | --- | --- | --- | --- |
| M01 | HTML／SVG／Canvas 动效：概念解释、片头、轻量广告 | Brief、形状／图标、事件表 → 页面源码与视频 | [平面矢量案例](cases/mg-01-flat-vector.md)；有本地复现与花园拓展记录 | 文本模型调用 + 浏览器渲染；复杂角色与叙事需要专门设计 |
| M02 | 连续线条／一笔画：品牌、简洁叙事、对象关系 | 形体链、路径、时间表 → 连续绘制短片 | [一笔画案例](cases/deepseek-onetake.md)；多部片技术通过，主观验收范围不齐；引擎代码已清理，做法见案例 | 路径设计与可读性是主要工作；跨模型泛化未证实 |
| M03 | 白板讲解：课程、操作原理、流程解释 | 解说稿、绘制顺序、板面布局 → 白板动画 | [白板试片案例](cases/lemo-whiteboard-trial.md)已输出；缺配音、真实逐笔字形等上游特征 | 字形、旁白和镜头配合；现有试片不可冒充完整风格复现 |
| M04 | 等轴／WebGL 空间叙事：系统、生产线、芯片、设施 | 对象／状态／连接、空间布局 → 空间动画 | [等轴案例](cases/mg-02-isometric.md)、[芯片案例](cases/mg-02-isometric-chip.md)；已有迁移，芯片视觉偏简陋 | 几何遮挡、阴影和子采样可能增加渲染时间 |
| M05 | 轮廓形变：标志、隐喻、对象接续 | 对应轮廓／部件、顺序与节拍 → 形变片 | [形变案例](cases/mg-05-shape-morph.md)；原版通过，WANDER v3 仅勉强接受 | 部件对应和形态辨识；平滑插值不保证自然 |
| M06 | Manim 数学／科学动画：精确几何、关系与推导 | 正确的对象／关系、解释顺序 → Python 场景与视频 | [ManimGL](../theory/extractions/projects/P05-manim-gl.md)、[Community](../theory/extractions/projects/P06-manim-community.md)；仅文档资料 | 环境与 API 差异；两种 Manim 分开固定版本 |
| M07 | React／Remotion 组件视频：产品、图文、系列模板 | 组件、媒体、配置与帧时间 → 可编辑工程与视频 | [Remotion 笔记](../theory/extractions/projects/P07-remotion.md)、[产品片来源](../theory/extractions/projects/P01-ai-promo-video-maker.md)；未在本项目完整跑通该流程 | 前端工程与素材准备；许可及自动化场景条款另行核查 |
| M08 | Blender 程序化三维：材质广告、接触与空间动作 | 场景、运动函数／模拟、材质灯光 → 三维工程与视频 | [三维案例](cases/mg-04-3d-render.md)；Soft Landing 与 RIPPLE 有结果及失败记录 | 原作 CPU 渲染历史记录约 9.93 小时；不能当作浏览器动效的成本 |
| M09 | 真实录屏 + 代码标注：软件教程、产品证明 | 实际操作录像／截图、功能事实 → 标注与剪辑视频 | [P01](../theory/extractions/projects/P01-ai-promo-video-maker.md)、[V05](../theory/extractions/videos/V05-BV1xGah67E1j.md)；本项目尚无完整录屏流程实测 | 真实素材采集、遮挡与版本更新；需要实际产品可用 |
| M10 | 数据／实证叙事：图表、地图、显微与档案 | 数据／真实图像、单位／出处、解释顺序 → 动态可视化 | lemo-opuscar 索引有数据、卫星、显微等风格；当前只核对索引，未逐风格提取 | 数据真实性、外部资产和图表设计；示例数据不能代替目标数据 |
| M11 | 资产拼贴／剪纸／2D 角色：知识、广告、风格片 | 照片、分层剪影、关节／纸张语法 → 合成动画 | [P02 拼贴线索](../theory/extractions/projects/P02-mg-styles-15.md)、[风格库](STYLES.md)；未本地验证这些风格 | 素材与抠图、层次和授权；“纯代码”也可能依赖照片 |
| M12 | 静态图分层与 2.5D 运镜：插画故事、图片短片 | 分层图片、遮挡／景深与运动 → 视差动画 | 分类占位；现有资料不足以给出经过核对的专门流程 | 需要补直接教程／工程；单图推拉不能产生真实新视角 |
| M13 | 参考图／首尾帧驱动视频：角色片、短镜头、情绪片 | 角色／场景参考 + 镜头动作 → 候选视频片段 | [V01](../theory/extractions/videos/V01-BV1Z28P6HEGa.md)、[P04](../theory/extractions/projects/P04-Table-VideoSOP.md)；有方法笔记，缺部分作者 Skill 和独立实跑 | 生成额度、失败次数、身份漂移与接续；界面演示不等于可调用 API |
| M14 | 纯文本生成视频：素材片段、氛围镜头 | 镜头描述 → 多个候选片段 | 分类占位；尚缺本项目已提取的直接完整来源 | 生成费、筛选与一致性；需要核查模型的真实规格与接口 |
| M15 | 数字人／口型同步：口播、课程、多语种 | 解说音频、人物资产／授权、字幕 → 口型与剪辑视频 | 分类占位；尚无本项目已提取的直接来源或工程 | 声音、人物授权、口型质量和服务／GPU 成本 |
| M16 | 旁白驱动的混合讲解：科普、报告、长内容 | 稿件／配音 + 真实证据 + 动效／生成素材 → 总装视频 | [V05](../theory/extractions/videos/V05-BV1xGah67E1j.md)、[P04](../theory/extractions/projects/P04-Table-VideoSOP.md)；文档已提取，未独立复现完整流程 | 时间线修改牵动多个步骤；可组合 M01、M07、M09、M13 |

M02、M03、M05 可以建立在 M01 上；M16 是编排方式，可调用多种技术。检索时保留多个标签，不把相似标签数量当作研究广度。

## 用途到候选路线

| 想制作的内容 | 先比较 | 必须准备的内容 | 当前可直接参考的材料 |
| --- | --- | --- | --- |
| 低预算概念动效 | M01、M02、M03 | 一句话目标、对象变化、少量素材 | 平面矢量、一笔画方法与白板试片 |
| 数学或机制解释 | M06、M04、M16 | 真实关系、正确数量／单位、解释顺序 | Manim、等轴／芯片、Anatomy 来源 |
| 软件／项目介绍 | M09 + M01／M07 | 真实截图／录屏、已核实的功能与卖点 | ai-promo-video-maker、Table-VideoSOP |
| 数据新闻／研究报告 | M10 + M01／M07 | 数据、来源日期、图表逻辑 | lemo-opuscar 数据与实证风格入口 |
| 有材质的三维广告 | M08，或适合的 WebGL 路线 | 模型、材质、灯光、动作、可用渲染时间 | Soft Landing／RIPPLE 的方法与结果（源码已清理，见案例） |
| 电影感角色短片 | M13 + 剪辑，或 M16 | 剧本、参考图、分镜、接续与声音 | V01 资产与参考绑定方法；生成层尚待验证 |
| 数字人口播 | M15 + 字幕／剪辑 | 解说、人物与声音资产 | 当前证据缺口，先收录来源 |

“低预算优先”是在满足表达目标的候选中比较总代价。复杂空间或写实人物若强行改成代码绘制，也可能带来大量人工和模型返修。

## 扩展分类的方法

新来源先匹配现有标签。只有在输入、核心步骤、输出或关键依赖发生明显变化时再增加方法标签；只是配色、题材或风格不同，优先增加风格／用途标签。新方法可以先标记为待补，不需要先验证才能进入目录。
