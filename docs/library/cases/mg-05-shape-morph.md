## Prompt 结构与规格

- 五段式上游模板（结构说明见 [mg-01](mg-01-flat-vector.md)）。
- 固定输出 1920×1080、30 fps、恰好 10.000 s（300 帧）、−14 LUFS、true peak ≤ −1 dBTP；建议路线 SVG + flubber 或 GSAP MorphSVGPlugin。
- 风格特征：轮廓连续过渡无跳变、中介形状桥接、形变伴随位移旋转、变形瞬间挤压拉伸。
- 技法：顶点数一致与首顶点对应（否则打结）；复杂 A→B 先收敛为圆／胶囊再展开（两段各 8–12 帧）。
- 全程叠加 10–15% squash & stretch 与轻微旋转；速度曲线 `cubic-bezier(0.7,0,0.3,1)`，起止各留 3 帧缓冲。
- 创意种子示例链：咖啡杯 →（圆）→ 太阳 → 海上日落 → 海鸥 → 纸飞机 → 定位针 → 心 → 字标“morphe”；背景色块随每次形变切换。

## 原版实现（拆解）

- 路径重采样后点数相同，再统一方向、搜索循环起点对齐，减少插值时边界互相穿越。
- `MP` 表为不同转换分别配置圆形中间态、旋转、运动控制点与压缩量——不是所有图形直接线性插值，也不是一套参数套到底。
- `blendParts` 分开处理主体、孔洞、细线和阴影：无法对应的孔洞收缩或展开，附属线条分时退出／进入，避免所有细节搅成一团。
- 主体形变、空间运动、背景变化与海平面遮罩相互配合。
- 视觉落点与展开事件来自公共时间表，配乐与声效据此安排。

## 实际结果（原文数字）

- 原作重建：300 帧、1080p、30 fps、10 秒；母版约 62.92 MB、预览约 7.43 MB。
- 重建约 −14.0 LUFS／真峰值 −2.2 dBFS（原片约 −14.1 LUFS／−2.6 dBFS）；逐帧 SSIM All = **0.974531**。
- 渲染中断恢复：原渲染没有成片或活动进程，但临时 FFV1 文件可完整解码 281 帧。
- 实际查看首帧后只补渲染第 281–299 帧，把 281+19 帧按连续 30 fps 时间轴重新编码并合成原配乐，没有用作者视频补帧。
- 恢复记录见原 `reproduction/recovery.json`；原进程记录前 270 帧约 230.8 秒，补渲染 19 帧约 14.8 秒，未把补渲染时间当整片耗时。
- 《WANDER》初版：10 秒／1080p／30 fps／300 帧；母版约 2.21 MB、预览约 0.66 MB；渲染合成约 80 秒；音轨约 −16.0 LUFS／−5.1 dBFS。
- 初版三段形变各 21 个时间样本未发现边界自交或面积塌缩；跳转 3.5 s／8.5 s 画面一致。
- WANDER v2：14 秒／1080p／30 fps／420 帧；渲染合成约 123.9 秒；音轨约 −16.0 LUFS／−4.9 dBFS。
- WANDER v3：10 秒／1080p／30 fps／300 帧，含 8 次快速形变；2026-10-19 按 v3 源码重新渲染，最终画面用本机 Edge 软件渲染并合成既有音轨。

## 用户反馈（原文）

- 原版：“整体看起来没有什么问题。”→ 原版效果验收通过（针对整体观感，不扩展为逐像素或所有声音细节一致）。
- WANDER 初版：“整体僵硬、衔接不足，原作利用形状相似性进行变化。”→ 迁移未通过。
- 鱼→鸟短研究：转换“还行”，但指出“鸟翼过大、缺少第二只翼”，并建议允许在转换中生长新部件。
- v2 长段落：用户接受双翼修改，但“担心长段落可能不丝滑，怀疑形态数量不足”；v2 未被认可。
- v3：用户认为节奏有所改善，但仍差原作神韵，最终表示**勉强接受**。

## 失败与未验证边界

- 初版虽通过几何采样检查，但缺少语义部件对应：鱼与正面海鸥的视角不同，停稳再变形的节奏进一步割裂动作——**无自交等工程检查不等于审美成功**。
- WANDER 只迁移了无孔洞简单轮廓；原版完整的孔洞拓扑处理、多部件分时组织与复合遮罩**未迁移**。
- v2 增加形态数量未能解决“丝滑”问题。
- v3 用快速形变 + 整屏换色也“不足以单独复现原作神韵”；位置变化应服务于形态和构图，既不全程锁死也不每次都移动。
- 检查中修正过飞鸟微动作的接入／退出包络（避免转换边界轮廓缩放跳变）、片尾位置曲线切线不一致、鸟转叶片前提前倒退。
- 音频脚本依赖工作目录（与用绝对路径读取输入的案例不同），运行器仅在执行音频时切到源码目录再恢复。
- 字体 Outfit 实为可变字体、按上游要求的文件名存放，不凭名称宣称二进制一致。
- 未完成主观审听；源音频保留“高频较少”提示。

## 对 VideoLab 可复用的要点

- **Workflow**：先定稳定形体的辨识度与先后 → 每对形体单独决定直接插值还是引入中间态 → 先检查轮廓方向与起点对应 → 主轮廓与孔洞／眼睛／线条分开处理，无对应关系的细节要有明确退出与进入 → 转换速度、位移与伸缩协同，稳定形态可微动但接入／退出保持连续 → 画面与音乐同源事件表，形变完成时的声效帮辨认落点 → 检查中间轮廓自交、面积塌缩、时间边界跳变，再看正常速度的节奏与辨识度。
- **Prompt**：迁移的关键不是“采样后插值成功”，而是**部件语义对应**：先 redesign 两端形体使身体／头部／眼睛可延续，再为每条贝塞尔段指定对应角色。
- 允许新部件从合理位置生长／分裂／收拢，用根部附着、遮挡与分阶段展开维持连续感。
- **质检**：几何检查（点数、方向、起点、自交、面积）与视觉流畅感分别验收；短研究（6 秒、无配乐）先隔离形状与动作问题；失败版本与短研究全部保留，不用新版覆盖。
