# 芯片运行过程：INSIDE ADD（mg-02-chip）

> 归档 2026-11-06。依据删除前的 `02-isometric-chip/README.md`、`METHOD.md`、`EXPERIENCE.md`、`extension/PROMPT.md` 整理，未重跑。本案例**没有** `DESIGN.md`，也**没有** `reproduction/` 目录——它是新写的教学示意片，不是上游原片复现。

## 来源与版本

- 方法基线：已获用户认可的 ISOPOLIS 等轴复现（[mg-02-isometric](mg-02-isometric.md)）。
- 上游固定 commit `49052d80bfaf9fa8412cc9710530e5e95a3b8d8c`（mg-styles-15，MIT）。

## 目标与题材约束

- 用等轴微缩模型演示一条 RISC-V 指令 `ADD x3, x1, x2`：初始 x1=3、x2=5、x3=0，完成后 x3=8，**源寄存器不变**。
- 18 秒、1080p、30 fps、有配乐和事件音效、无配音。
- 原文的知识边界：ISA 定义运算语义，不规定模块位置、动画耗时或实现。
- 五个章节是教学叙述顺序，**不等同于五级流水线，也不代表五个时钟周期**。
- 省略 PC、指令编码、流水线重叠、缓存、旁路、乱序与实际晶体管。
- ADD 本身不需要数据内存读取，片中存储器只表示指令来源；外框引脚只提供芯片视觉意象，不表示真实封装布线。

## Prompt 结构与分镜（删除前 `extension/PROMPT.md`）

创作要求直接写明了可验证的状态变化：

- 读取不改变源值；ALU 先得到 8；结果移动到寄存器组，到达后才把 x3 更新为 8。
- 标题与模块名始终可读；结尾保留观察时间；配色为蓝绿、暖白与金色。
- 模块包括指令存储器、译码／控制、寄存器组、ALU，并标明是简化示意。

| 时间 | 内容 |
| --- | --- |
| 0–4 s | 建立空间，指令从存储器传向译码模块 |
| 4–6.5 s | 明确加法、两个源寄存器和目标寄存器 |
| 6.5–10 s | 数字 3、5 沿两条路径进入 ALU，源值保留 |
| 10–13 s | 显示 3+5=8，x3 仍为 0 |
| 13–15 s | 结果 8 沿回写路径返回寄存器组 |
| 15–18 s | x3 更新为 8，保持结果和全局构图 |

## 工程与渲染要点

- 稳定空间：四个模块位置固定，减少观众重新定位负担。
- 状态与画面分离：`state.mjs` 独立描述阶段、源值、ALU 结果与提交后的 x3，场景标签读同一状态。
- 不变量：两个源寄存器始终保留原值；ALU 结果先于写回；结果到达后 x3 才更新；用定点检查覆盖关键边界。
- 视觉层：Three.js 圆角模块、阴影、8 次内部子采样；DOM 标签投影到模块位置；数据标记沿路径按时间运动。
- 声音层：共享事件表触发章节提示音；轻配乐，未加未经审听的语音讲解。
- 首轮关键帧发现数字到达 ALU 时贴近模块文字，移动 ALU 标注为路径和数字留空间——比加装饰更直接地改善流程阅读。

## 实际结果（原文数字）

- 18 秒、1080p、30 fps、540 帧；母版约 11.31 MB、轻量预览约 1.16 MB。
- 渲染与封装 143.0 秒（不含音频制作与检查）。
- 全片解码通过；封装后约 −16.0 LUFS／−2.2 dBFS。
- 原始音频约 −16.03 LUFS／−2.23 dBTP，无削波。
- 已看 18 格时间分镜与结束画面；数值流向、步骤提示和最终寄存器值一致。
- 随机定位至 8.5 s 与 15.5 s 后回看，画面哈希相同、无页面错误。
- 检查器首轮因本地检查服务器未设置 `.mjs` MIME 类型而等待超时；修正检查服务器后通过，成片渲染服务器不受影响。

## 失败与未验证边界

- 只有概念、状态、关键帧与文件技术检查；正常速度观感与主观审听由用户检查，未预先宣称教学效果通过。
- 未把“讲通流程”等同于完整复现原版的视觉完成度。
- 声音审计提示低频较薄，且与上游默认 −14 LUFS 目标不同；本次主动选较轻的 −16 LUFS，提示保留、未声称完成主观审听。
- 没有 `DESIGN.md`／`reproduction/`：本案例的设计依据是 METHOD 与 Prompt，缺少像其他案例那样的原片对照与逐帧拆解记录。

## 对 VideoLab 可复用的要点

- **Workflow**：把“教学内容正确”做成可检查的状态模型与不变量，再让画面标签读同一状态。
- 先审知识边界（哪些机制被省略），再设计动画步骤，避免用漂亮运动掩盖概念错误。
- **Prompt**：题材 brief 里直接写清初始值、终值、保留不变量、禁止暗示（“不表示真实周期／布线／存储读取”）和必须始终可读的标签；这比“做个芯片动画”更能约束执行。
- **质检**：状态定点检查 + 关键帧检查 + 随机定位哈希 + 解码检查分层做。
- 检查服务器与渲染服务器的配置问题要分开定位（MIME 类型问题不代表成片坏了）。
