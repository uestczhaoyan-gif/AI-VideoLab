## 来源与背景

用户定制的本地白板讲解片，主题是微纳光子器件设计中的伴随法（adjoint method）。三版都在 2026-10-30 制作，复用固定版本 LemoLab 白板引擎（MIT，`b5e8ef93930b6d828f352055a689320f138237b1`），没有调用文生视频模型或在线语音 API。用户先要求 30 秒直觉版，再要求解释「为什么两次求解够」的 48 秒版，最后要求含核心公式的 96 秒专业版。

## 讲解结构（可复用模板）

- v1：逐笔写标题 → 逐个改像素仿真代价高 → 正向场 → 由目标构造伴随源 → 两场组合得到梯度 → 拉回整板总结。
- v2：先问「改哪个像素」→ 小材料改动等效为弱源 → 正向场决定等效源强度与相位 → 伴随场给出各处影响权重 → 两场逐点组合得全区梯度 → 正负梯度示例 → 迭代与「两次」的限定。
- v3：目标与参数梯度 → 离散方程 `A(p)E=b` → 微扰方程与逐参数代价 → `J=|cᴴE|²` 的复场敏感度 → `Aᴴλ=g` 伴随场 → 消去扰动场 → 全参数梯度公式与 `N+1` vs 2 次求解 → 更新、迭代与制造边界。

## 科学口径

- 「两次求解」指典型线性、单频、单激励、单实标量目标、固定 `b` 与固定模式投影且 `J` 无显式参数依赖时的一轮梯度计算；多激励、独立目标或频率需求可能需要更多求解，不保证全局最优。
- 伴随源由目标函数对场的导数决定；反向箭头是示意，不表示把真实光源倒放等价于伴随求解。板面点积是解释性关系示意，不是通用完整梯度公式。
- 器件、光场、正负敏感度与更新图案均为原理示意；未运行 Maxwell／FDTD 求解，没有性能、效率或收敛数据；结构更新图不是已验证可制造的器件。
- 来源依据是 Meep 官方 Adjoint Solver 文档开头第 1–100 行（2026-10-30 读取）与其中引用的 Hammond 等 2022 论文信息；未通读全文、未运行教程。

## 可复用经验

1. **单一时基 + 单笔全局调度**：笔画事件表同时驱动画面、字幕、旁白、音效；串行约束写进 `brief.json`，用帧级状态检查验证，而不是靠肉眼。
2. **分段渲染与局部返修**：按 6 秒分段导出无声片段，再合一条连续音轨；改标签只重渲受影响片段，避免全片重来与音频接缝。
3. **本地可复现链**：浏览器逐帧截图 + FFmpeg + 本机离线 TTS，不依赖在线服务；代价是字体／笔顺数据与引擎版本必须固定并保留许可。
4. **技术通过 ≠ 验收**：解码、响度、0 丢帧、笔画无重叠都可以自动化；主观试听、完整观看和用户采用必须单独记录，不能互相替代。
5. **知识深度与视觉风格分开**：同一白板风格可以承载 30 秒直觉、48 秒因果和 96 秒公式推导；加公式不是把更多文字塞进短片，而是重排节奏与停留时间。
