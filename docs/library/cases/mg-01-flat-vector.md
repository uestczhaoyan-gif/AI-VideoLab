## Prompt 结构（上游模板，五个案例共用骨架）

- `Style` 风格名。
- `Output (fixed)` 固定规格。
- `Suggested technical route` 建议路线（允许说明理由后更换）。
- `Creative seed` 按时间写故事与收尾。
- `# Signature features` 可检验的风格特征。
- `How to work` 六步：Treatment → 关键帧 → 运动 → 声音 → 终检 → 自评。
- `Rules`：逐帧确定、素材许可、文字正确；另有 `Craft checklist` 与 `Deliver`。
- 本案例固定规格：1920×1080、30 fps、恰好 10.000 s（300 帧）、H.264 + 48 kHz 立体声 AAC、−14 LUFS integrated、true peak ≤ −1 dBTP。
- 建议路线 SVG + GSAP；风格特征写死纯色大色块、无渐变、5–6 色品牌色板（示例 `#2B2BFF` 群青／`#FF5A4E` 珊瑚／`#FFC62B` 向日葵／`#2EE6A8` 薄荷／`#FFF6E9` 奶油／`#151433` 墨）。
- 运动规则：stagger 2–4 帧、同一时刻只让一个主体动、squash&stretch 约 10%、元素带动转场。

## 工程与渲染要点

- `renderAt(t)` 把状态分发到世界／室内／图标／字标四部分；对象状态由 t 计算，可随机跳帧，不依赖实时播放累积状态。
- 镜头是坐标变换：世界放在组内，镜头用平移与缩放定位；缩放跨数量级时在对数空间插值，接近玻璃时加速、抵达后过冲回稳。
- 弹性分层：`ballA()` 分段（自由落体、触地压扁、小跳、蓄力、弧线）、`spring()` 过冲衰减、`kick()` 短扰动；主动作与余波分开调。
- 字体是工程输入：用字体测量得到字形宽度与点位，把柱体接到字母 i；缺字体会改变这段转换。
- 画声共用一份 `cues.json`；音乐分 build／drop／outro，动作配 pop、whoosh，视觉重击前短暂让位。
- 拓展的实际修订：修正 JS 幂运算语法；发芽与种子淡出增加交叠；镜头跟随种子并随生长退开；低对比花瓣改蓝；降低主花高度避免压副标题。

## 实际结果（原文数字）

- 原作重建（2026-10-13）：300 帧、10.00 s、1920×1080、30 fps、H.264 + 48 kHz 双声道 AAC。
- 重建音画：约 −14.0 LUFS、真峰值约 −2.2 dBTP；渲染与合成约 20.4 秒（不含环境配置、下载、配乐生成与检查）。
- 拓展（2026-10-14）：“种子长成花园”10.00 秒、300 帧；约 −16.0 LUFS、真峰值约 −3.9 dBTP；主动选较轻配乐与 −16 LUFS。
- 重检：300 帧、时间基准 1/30、显示时间戳步长均为 1、无相邻完全相同帧。
- 随机跳转后重渲 3.5 s 与 8.5 s，像素哈希一致、无页面错误；另查看十个时间点与结尾大图。

## 失败与未验证边界

- 卡顿原因未定位：时间戳与重复帧检查只能排除时码间隔异常与完全重复帧，**不能**排除缓动／阶段切换的停顿感或播放器卡顿；未改动用户已认可的版本。
- 助手未做实时完整播放与主观试听；用户反馈不细分画面与声音。
- `matplotlib 3.9.1` 本机源码编译失败，改用有 Windows wheel 的 3.9.2；首次合成音轨填充把容器拉到 10.58 秒，按帧数补 `-t` 后回到 10.00 秒（早期错误记录另存）。
- 音频检测器提示 60 Hz 以下约 54.24%，属主动选择 −16 LUFS 的差异；保留频谱提示但不作质量结论。
- 渲染器上游监听器警告仍在；运动模糊沿用源码默认 `mb=1`，原片部分帧模糊更明显；字体中文字重作者未发布原文件，不能宣称字节一致。
- 只验证了一个新概念；场景变化与戏剧性仍比原作简单，单次认可不能推广为方法已验证。

## 对 VideoLab 可复用的要点

- **Workflow**：主题／感受 → 找可视化主角或关系 → 写“状态→触发→结果”变化链 → 选场景构图转场 → 对象层级／坐标／路径／时间表 → 画面代码 + 声音事件 → 渲染、观看、再修改。
- **Prompt**：可复用骨架是「先理解参考的设计机制（区分事实与推断）→ 为新主题重新设计，不只换字换色 → 给出设计说明并转成对象层级／坐标／共享事件表 → 关键帧先检查 → 交付源码、依赖来源、命令、成片、检查与修改记录」。
- 具体数值（10 秒、调色板、落点）是案例参数，不写死。
- **质检**：关键帧先看主次与构图；确认任意时刻可重渲且哈希一致；FFmpeg 核时间戳／重复帧；完整观看与审听单独记录，不能以抽帧代替。
