## 目标与交付

1. 复现原作默认 10 秒独立片（不启用 `v5` 汇编版）。
2. 拆解“连续细线如何构成叙事”。
3. 新概念拓展《归途》：山峰 → 河流 → 桥 → 家门。

## Prompt 结构与规格

- 五段式上游模板（结构说明见 [mg-01](mg-01-flat-vector.md)）。
- 固定输出 1920×1080、30 fps、恰好 10.000 s（300 帧）、−14 LUFS、true peak ≤ −1 dBTP。
- 风格特征：等宽细线、单色或双色、大量负空间、线条连续生长、线面转换。
- 关键技法：`stroke-dashoffset` 描绘；线宽全片恒定（2–4 px）；转角以 `cubic-bezier(0.65,0,0.35,1)` 略减速。
- “上一形尾线即下一形起线”；描完轮廓后用同路径 `fill` 从锚点扩展；round cap 与轻微抖动增加手绘感。
- 创意种子给出深蓝底 `#0B1320`、香槟金 `#E9D7A5`、约 3 px 线、笔尖是引路的柔和光点，以及“种子→树苗→建筑→天际线→标志→填金→字标”的连续路径。

## 时间轴与叙事

- 叙事链：植物、建筑、天际线、浪与标志共享一条轨迹；观众跟笔尖理解下一个形体如何出现。
- 镜头先显示局部，再退到完整海报；前面的行进因此获得整体意义。
- 大量暗色留白让细线成为主角；最后金色实体改变视觉重量，形成高潮。
- 代码对应：`PIECES` 描述分段路径；SVG 提供路径长度与采样位置，Canvas2D 最终绘制。
- 路径采样生成距离、曲率与分段信息；`cues.json` 设置段落、停顿与推进；复杂转折不按相同速度机械划过。
- 标志在指定时刻由线转面；反向光脉冲把高潮与之前的整条轨迹连起来。

## 工程与渲染要点

- 镜头与绘制轨迹共享时间，但相机不是直接锁死在笔尖：它安排预留空间、转折与结尾退镜。
- 材质：线条 + 局部柔光 + 纸面颗粒 + 笔尖光；光效辅助阅读，不取代清楚的线形。
- 声音读公共事件和路径导出的 `out/timing.json`（保存从路径推导的转角与速度数据，**不是可丢弃的渲染缓存**）。
- 笔触声、停顿与音乐重音共同组织节奏。
- 复现依赖除源码与字体外，还包括共享纹理 `assets/textures/grain/grain_fine_2048.png`；缺它时场景首次检查报图片解码失败，补取上游原文件后通过，未用临时自制纹理替代。
- 《归途》复用字体、颗粒、离线渲染与音色库；分段缓动。
- 《归途》不具备原版完整的曲率／屏幕速度驱动，也未复制“枝条变梁”的局部形变机制。

## 实际结果（原文数字）

- 原作重建：300 帧、1920×1080、30 fps、10 秒；母版约 6.50 MB、预览约 2.18 MB。
- 渲染与封装约 204.8 秒。
- 原片／重建封装后响度约 −14.1／−14.1 LUFS，真峰值均约 −1.2 dBFS。
- 逐帧 SSIM All = **0.994781**，不能理解为审美还原百分比。
- 七个关键事件的音频起音对齐检测按作者阈值通过，但不等于主观审听已通过。
- 《归途》：12 秒、1920×1080、30 fps、360 帧；母版约 2.88 MB、预览约 1.29 MB。
- 《归途》渲染与封装约 152.7 秒；输出音轨约 −16.0 LUFS、真峰值 −4.2 dBFS。
- 《归途》3.5 s 与 8.5 s 重复定位画面一致、无页面错误；片尾字标／文案完整可见。
- 实际修订：第一版家门带宽屋檐，填金后近似上箭头；关键帧检查后收窄轮廓、去掉两侧伸出的屋檐，保留尖顶与门洞。

## 用户反馈（原文）

- 原版：“画得很好，很喜欢这个效果和风格。”→ 原版复现通过。
- 《归途》：“有那个意思了”，初步迁移通过。
- 《归途》同时强调：**一笔画必须先规划表现形式的先后，否则会乱**。

## 失败与未验证边界

- 环境：上一次下载中断留下两枚 Git 锁，确认无 Git 进程后只清理对应锁并恢复固定版本稀疏检出。
- 音频审计提示 2–5 kHz 能量偏强；《归途》保留“低频较薄”提示；两者都不等于主观审听已通过。
- 效果与声音的最终判断仍待用户正常速度观看；当前方法尚未完成“真实屏幕笔尖速度驱动”的迁移。
- 保留默认 4 次运动模糊采样与 0.5 快门参数。
- 编码、颗粒、字体版本与色彩元数据可能带来差异，未声称逐像素一致。

## 对 VideoLab 可复用的要点

- **Workflow**：先选有连接关系的对象 → 先画最终构图并给片尾文字留空间 → 路径长度驱动显露、分段速度与停顿 → 镜头引导注意力并检查笔尖全程在画内、最后退回整体 → 只做一次线面转换 → 声画共读事件表 → 检查接缝、任意时刻定位、文字裁切、完整帧数与音轨 → 正常速度观看。
- **Prompt**：迁移的是“连续的形体关系、可追踪的笔尖、局部到整体的镜头、速度变化、一次线面转换、与运动相关的声音”；城市、门洞标志与固定秒数是原片选择，不复制。
- 新片 brief 要写明保真边界（“分段包络”≠“按真实笔尖速度驱动”）。
- **质检**：用户观看后补充的核心约束已进方法——先规划“观众依次看懂什么”，再规划“线怎样连过去”；给每个形体足够辨识时间；不为不断线而绕路、交叉、回描；最终构图与动态过程分别验收。
