## 1. 问题定义与职责边界

**P04-C01〔作者表述〕**：把已经确认的文案和配音做成可分段协作、可继续修改、画面有信息增量的视频。用户负责内容、风格与采用决定，Agent 负责规划、任务准备、动画后期、检查和记录；生图／生视频由用户在工具中手动完成。

**P04-C02**：以定稿配音为主要时基。内容、停顿、顺序或长度变化会影响画面、声音点与字幕。配音未定时只能先做不依赖正式时基的工作。

**P04-C03**：文案检查、音效与配乐制作属于可选模块，不选用不应阻断主流程；但已采用声音仍须检查。可选的是制作模块，不是对实际交付质量负责与否。

## 2. 原文所述完整流程

环境与系列设计测试 → 稿件／配音确认 → 制作大段表 → 分段任务准备 → 镜头剧本 → 视觉设计图与全片总览 → 制作 → 总装锁画 → 声音／字幕 → 最终 QA → 封面与发布材料 → 复盘。

**P04-C04**：按叙事任务、视觉关系、技术路线或风险变化划大段，不机械按每句话或每个镜头建立任务。一个完整关系可以跨多句，开场可以单独打磨。

**P04-C05**：每段都回答配音已提供什么、画面新增什么关系／证据／情绪、必须保留哪些文字。只把配音变成大字需要重新设计。

## 3. 文件与多会话协作

**P04-C06**：总控维护采用版本、中央状态、共享组件和总装；分段只写专属目录，并交接源码、参数、时间范围、首尾状态、原声策略和检查证据。

**P04-C07**：并行不等于复制多套依赖或多个正式工程。一期保持一个正式入口；有真实依赖冲突或试验风险时才单独隔离，说明回收与接入方法。

**P04-C08**：区分输入、采用和检查。新文件不是自动采用版，允许制作不是已经验收。稿件、采用表、正式工程和 QA 各管不同事实，避免多张中央表互相冲突。

**P04-C09**：任务书绑定具体输入和表版本，公共变化由总控处理。表变化只暂停依赖旧版的部分，其余工作继续。

这些是作者 SOP 的协作设计，本次仅提取，不对当前 VideoLab 增加会话、审批或目录负担。

## 4. DESIGN 的作用

**P04-C10〔作者表述〕**：DESIGN 不是只列颜色字体，还要表达运动、图形语义、包装与确认范围。先做实际静态与动态测试，再把采用值写入规则，避免空模板直接进入实现。

使用 `google-labs-code/design.md` 的基础字段，并添加 `x-video` 描述视频画布、图形语义、动作曲线和证据。作者明确：视频扩展是本包的约定，不能声称上游 CLI 已验证这些视频语义。

**P04-C11**：结构校验、代码实现是否采用参数、真实视觉效果是三层不同验证。JSON 能解析不证明画面好，静态样图也不证明动态效果。

**P04-C12**：Agent 从确认样本提取参数，用户判断实际效果；不要求用户手工填写全部设计 token。正文引用参数，派生配置从同一来源生成，避免双份数值漂移。

## 5. 从口播到视觉叙事

**P04-C13**：先写对象如何变化，再做设计图。对象被处理、失真、传递、受阻或交接，构成画面信息；整体卡片淡入淡出和装饰漂浮不能替代核心过程。

**P04-C14**：同一对象优先连续演化，用拆分、合并、组织关系、数量或位置说明变化。表示“处理”时必须能指出处理前后的具体差异；进度条满了和打勾只是反馈，不是过程解释。

**P04-C15**：必要标签帮助辨认，但不能承包叙事。作者提出删字、静音、合看、与对标片连看等检查，分别观察关系、变化、声音协同和质量回归。

## 6. 时间分配比盲调曲线更先行

**P04-C16**：变化越大、同时变化的元素越多，通常需要更多时间，但不按距离简单成比例增长。过渡本身也需要独立动作预算，不能使用配音词点之间的零头硬塞。

**P04-C17**：突然或太快时，先检查动作总时长、变化量、预备和停稳，再调缓动。曲线不能补救总时间不足。反过来，多余时间必须用于可观察过程或必要阅读，否则会拖沓。

作者提供了自己系列中的校准例：长距离传递沿用约 0.77 秒显得突然，调整到约 1.15 秒后获认可；另一次过长变形和过短让位重新分配时间后改善。这些是作者个案，不是跨题材固定值。

**P04-C18〔需保留的张力〕**：文档一方面反对跨系列照抄时长，另一方面把约 0.3 秒内完成主要变化描述为过短的下限。应保存原说法与使用背景，不能把这个判断推广到所有剪辑或快切。

## 7. 镜头与素材要同时设计

**P04-C19**：在画面方案阶段同时决定主体变化和观察方式，不先排满正面版式再给整图加缩放。镜头要说明跟谁、揭示哪里、何时落稳；固定也可以成立，但应服务段落任务。

原文区分：推拉、横移升降、摇镜、环绕、摇臂、跟随／主观穿行、视差、变焦、焦点转移、滚转、滑动变焦、冲击抖动。它们分别改变位置、方向、视角或对焦，不应混称。

**P04-C20**：二维整体缩放能模拟尺度改变，不能凭空产生视差、另一侧面或纵深。固定窗口内缩放内容属于界面缩放，不等于摄像机真正推入场景。

**P04-C21**：比较、接触和结果阅读需要稳定时段，不意味着整段固定；物体已经在动、有文字，也不自动排除镜头设计。不为凑运动种类做无目的推拉。

## 8. 转场与连续性

**P04-C22**：共享元素演化、图形匹配、动作匹配、遮挡过镜、声音桥接各有不同作用；作者强调观众能跟住对象身份、方向、动作阶段和结果。

**P04-C23**：运动匹配先设计成对镜头，再对齐屏幕位置、尺度、方向、动作阶段和速度。前镜的运动由后镜继续，不要两边各自缓出归零再硬接。

**P04-C24**：切点服从可见动作，不一律设在速度峰值。旋转核对转轴和角速度，缩放核对中心与大小，平移核对接缝覆盖。先修几何跳位再决定模糊量，不靠越来越重的模糊掩盖问题。

**P04-C25**：裁切、变速、入点改变后重新标记声音和接点。下一场声音提前或上一场延续可以桥接，但不能改变已确认语义时序或提前暗示事实。

## 9. 样片与对标

**P04-C26〔作者方法〕**：同类型段落直接对照已确认作品，新镜头方式、空间、互动、转场、风格或技术才先做代表样片。多句话或内容不同本身不等于新技术类型。

**P04-C27**：样片必须覆盖真正难点，不能用简单标题入场证明复杂接触或状态变化可行。已指出却未解决的问题需要优先验证，再扩展。

作者描述一段 MG 的三版演变：前两版动态不足或只改变位置与透明度，第三版让同一对象经历处理、失真、影响下游、继续处理和交接，才得到确认。作者希望同时保留“动态不足”和“表达不成立”这两种问题，避免只修其中一项。

## 10. 生成素材的分工

**P04-C28**：参考图按身份、画风、构图、场景／道具分工，说明采用与不继承什么。角色名称不能替代外观约束；已经通过的图也不自动成为尾帧。

**P04-C29**：生成片适合隐喻、空间和情绪，真实操作或准确结果仍需真实材料。精确文字可以后期叠加，也可对少量生成标签逐字验收，不规定所有底图绝对无字。

**P04-C30**：多步动作维持不了身份或因果时拆短镜；后续接续从实际采用画面取帧。生成提示词的计划时间不等于实际动作发生时间。

**P04-C31**：底图错就改底图，动作错只处理视频层，画面好而声音错只处理声音。保留正确部分，有助于控制返工范围。

## 11. 声音不是逐动作打点

**P04-C32**：先定义一段声音要表达的变化，再选择事件。一个连续动作可用一条连续声音，已有原声或音乐足够时不再叠加。

**P04-C33**：先识别音效的实际可闻起点／峰值，反推放置时刻；处理过音频后重新核对。持续运动声音的起伏与收束应解释得通，不能尾音拖入静止或下一句。

**P04-C34**：一次落地听成多次时逐层旁路，重点不突出时先撤掉竞争背景，不一定整体加响。配音、BGM、SFX 和原声分别控制，避免重复音轨。

**P04-C35**：响度、峰值和 ASR 只辅助诊断，不能替代主观听辨。ASR 新增差异触发对应区间检查，不直接判定背景音乐有错。

作者把 −16 LUFS 等数值明确写为口播试混起点而非平台标准；背景让位、恢复时间和音效增益都需按采用素材判断。该表达应与其他来源宣称“统一标准”的说法分别保留。

## 12. QA、返修和经验沉淀

**P04-C36**：QA 使用通过／未通过／未验证／不适用，绑定具体文件、版本、范围与证据。1× 完整审看审听不能被抽帧、波形或解码替代。

**P04-C37**：动态脚本找静止、过快和空帧，只定位问题，不自动判定艺术效果。不能实时观看的 Agent 仍应先修可观察问题，并明确余下验证缺口。

**P04-C38**：返修前明确本轮改动、保持项与复查范围。只改音频不重做动画；同路径内容变了不能沿用旧通过状态；只改名且哈希相同可复用内容证据。

**P04-C39**：反馈原话进入 QA；复盘区分规则未写和写了没执行，分别进入通用经验、系列偏好或本期特例，并列可删规则。经验沉淀包含删除，不是无限增加规范。

## 13. 作者披露的验证边界

README 说明做过不继承原对话的路由检查，并在自己的系列中用约 18 秒测试片验证镜头剧本、同类型对标与动态自检。测试后补充的窗口框规则尚未复测；全新电脑安装、完整视听成片与视觉质量的独立复现仍未验证。

因此这是有实践来源和有限自测的资料包，不是已经证明任意模型／主题都能成片的引擎。公开仓库不提供完整制作工程、生成服务或角色素材包。

## 14. 后期研究问题

规则路由是否比全量长 Prompt 更容易执行？以配音锁定时基带来多少稳定性与修改代价？新类型样片能否减少返工？同类型对标是否会让风格保守？质量判断、采用状态和输入记录分开维护，是否降低错误交付？这些问题留待实践结束后汇合分析。

重复观点（时间表、真实证据、完整视听、局部返修）故意保留在本文件，不因 P01/P02 已出现而删除。与“每个动作都配声”等其他来源冲突的地方，也暂不替作者消解。
