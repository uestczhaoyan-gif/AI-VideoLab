## 4. 03:44–05:33：第三章 · AI 原理：大脑与手脚

**V11-C11〔口播转录〕**：平时说的 AI 大部分其实是大语言模型；可以把它理解成一个“大脑”：读过特别多的东西，你跟它说话它能听懂、能回答、能帮你写东西甚至写代码。它跟搜索引擎不一样：搜索是帮你找别人写好的东西，而它是根据你的问题现场想一个答案出来（转写有口语重复，按语义整理）。

**V11-C12〔口播转录〕**：光有大脑不够：它没有手脚，碰不到你的电脑、也上不了网；你问它，它答你，答完就完了（原转写“你问他 他打你 打完就完了”为识别误差，按上下文校正）；真正动手的还是你自己。作者说自己这三个月就是在一步步给这个“大脑”接上手脚。

**V11-C13〔口播转录 + 画面〕**：真正花时间改的是背后这套 skills：在使用过程中反复跑、反复改，花很久才到“能先给大家用”的版本。没加的时候也能做，但有时文字排版、节奏比较乱；加了以后整体明显统一一些。画面 05:20–05:30 是 v3 Skills 堆栈与循环“先跑起来 → 发现问题 → 回头修订 → 再运行”，字幕“反复跑、反复改，很久 / 才改到现在这个能先给大家用的版本 / 整体明显统一一些”。

**V11-C14〔本项目观察·异常，成因未核实〕**：转写显示 03:41–04:26 与 04:29–05:10 有两段近乎逐字相同的口播（“先简单说一下 我们平时说的 AI…大脑…手脚”，合计约 85 秒），画面分别是 DeepSeek 与 Codex 两组对比。本机对两段做语音频段（250–3500 Hz）包络互相关，最高仅约 0.14，说明它们不是同一段录音的简单复制；更像同一脚本的两次近似录制，或两个不同播放源。转写误差、混音差异都可能影响判断，此处只记为观察，不推断作者意图。

**V11-C18〔口播转录 + 画面〕**：做完动画以后，记得让 agent 帮你检查，把生成过程里不用的临时文件、缓存清理干净；成片和还要继续修改的原文件先留好，别乱删，不然用多了 C 盘会越积越多。画面 06:30：“缓存这些清理干净 / 临时文件缓存 / 核对后清理 / 收走”。

**V11-C19〔口播转录 + 画面〕**：网上很多“一键生成动画 / 一键拆剧本 / 一键分镜”、包括 ComfyUI（原转写“康费 UI 工作流”，按语境推断为 ComfyUI，标注不确定）工作流，本质也是把原本要做的事拆成步骤，再调模型、节点和参数，把流程做得简单一点。作者对把别人开源的东西稍微改一改、套个壳就开始卖、还讲得特别神秘的行为有意见：尤其是拿现成几种 MG 动画风格套壳、没做多少东西就卖的，劝大家别为这种付费；真能解决问题、帮你省时间，收费没问题，有意见的是“拿别人做好的东西包装一下，让你觉得学不会只能花钱买”。画面 07:00–07:20 对应“开源 → 稍微改一改 套个壳 就开始卖 / 信息差 / 特别是那种拿现成的几种 MG 动画风格套个壳 / 真能解决问题 帮你省时间 / 别为包装买单”。

**V11-C20〔口播转录 + 画面〕**：上一期评论区有不少“模型中转站”广告让大家充值；这种来路不明的东西要小心。中转站简单说就是：你把请求发给它，它再转给模型；有正规服务，但也有人页面写着高端模型、后台却给你换成成本更低的模型——你花了钱，觉得 AI 怎么突然降智了，还以为是官方模型变差，其实可能是中间这一层有问题。别因为它写着 Claude/OpenAI 就认定真的在用那个模型；评论区随便发的充值广告不要轻易相信，更不要把账号密钥交出去。哪些靠谱、怎么辨别，作者说后面再讲。画面 07:30–08:10：“你 → 中转站 → 模型”“来路不明·先别信”“后台却给你换成成本更低的模型 你花了钱”“其实可能是中间这一层有问题”“名字 ≠ 后台保证”“不要轻易相信 更不要把自己的账号密钥交出去”。

**V11-C23〔口播转录 + 画面〕**：真正重要的是：你自己想做什么、你的眼光/审美/感知/判断是什么。AI 就是一个工具；我们最熟悉、最简单的表达工具是文字；如果有一天用 AI 也能像写字一样简单，为什么有的人写出来的是诗、有的人写出来的是流水账？区别还是在每个人自己身上：你看见了什么、感受到了什么、想表达什么，这些才是你自己的东西。代码动画只是一种形式，AI 漫剧、音乐、电影也一样；所以除了学工具，也得慢慢提高自己的审美、认知和感知。画面 09:30–10:10：“AI·一种表达工具”“诗”“有的人写出来的是流水账？”“看见·感受·表达”“工具 vs 自己”。
