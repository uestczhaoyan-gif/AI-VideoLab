## 7. 04:18–05:36：如何交给自己的制作 Agent

**V06-C10〔作者方法〕**：让自己的 DeepSeek harness 读取文件夹，选择对应提示词；用户还需说明想表达什么、镜头怎样走、多个风格怎样分工，以及是否需要音乐与音效。

```text
明确主题与受众
  → 选风格／运动／版式
  → 读取完整 Prompt，补内容与镜头要求
  → 制作模型写代码
  → 渲染并检查实际画面
  → 明确补充声音与导出要求
```

“让 harness 读文件夹”需要具备本地文件、工具与执行权限的 Agent，并非普通网页聊天自动拥有这些能力。仓库后来提供的导出接口另见 P09，不冒充视频中已验证的通用渲染链。
