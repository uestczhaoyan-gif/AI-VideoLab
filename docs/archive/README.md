## 没有删除或搬动什么

- `demo/`、`DeepseekDemo/` 的代码、Prompt、方法、检查、成片和失败版本保持原路径。它们是可复用资产和证据，不能仅因暂不进入工作台就判为垃圾。

- 上游快照、ZIP 与采集证据仍保留在原忽略目录。本机有些渲染／恢复脚本依赖这些路径，本轮不整体迁移。
- 没有执行 Git 重置、历史重写、`git clean`、批量删除媒体或卸载环境；此前未提交修改保留。

本次整理解决的是有效入口、职责重复和指令冲突，不声称磁盘体积显著减少。整理前本机测量约 6.7 GiB（含 `.git`、环境、上游和输出），其中 `demo/` 约 3.8 GiB、`docs/` 约 1.9 GiB、`DeepseekDemo/` 约 339 MiB，体积随缓存变化。

## 大文件后续处理原则

先区分可重新获取的下载包、可重建缓存、尚无恢复说明的依赖、唯一采集证据、最终输出和失败记录。对可清理项先确认固定版本、哈希与恢复方法，列范围后再清；不把“在忽略列表里”当作可以删除的依据。

旧结构快照中的文件数和大小只代表其记录日期，不是当前实时统计。Git 已有媒体历史不能靠移动目录或新增 `.gitignore` 解决；LFS、Release 或历史瘦身须单独决策，不混入本次产品整理。
