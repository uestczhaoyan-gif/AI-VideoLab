# 科学视频制作研究：重新开始

> 将本文交给新的项目对话，作为任务说明。先做出一个好镜头，再总结方法。

## 目标

研究如何用 AI 辅助制作科学准确、形象生动、视觉精美的视频。主题以光学、物理和 AI for Optics 为主，面向相关专业学生，同时吸引普通观众。

观众看完应能记住一个具体物理图景，并预测一个条件改变后的结果。科学正确、直觉清晰、视觉吸引力分别验收；公式正确、程序通过或视频成功导出，都不等于作品完成。

## 研究顺序

1. **选一个小问题、少量参考。** 从可实际观看的 3Blue1Brown、Vibe 知识大赏、B 站作品中选择相关片段，同时寻找作者说明或开源工程。
2. **看懂具体方法。** 按时间点分析问题如何提出、机制如何呈现、场景怎样连接数学表示，以及构图、对象、运动、文字、节奏和声音如何配合。区分实际观察、作者声明、推测与复现结果；无法观看就说明，需要时请我提供片段。
3. **提出两种实质不同的方案。** 解释各自如何帮助理解、需要什么工具与资产，不能只是换配色。根据镜头需要使用代码动画、三维建模、合规资产和剪辑工具。
4. **先完成一个短镜头。** 先做实际渲染的关键帧，再制作约 10–20 秒、包含一个完整解释动作的短片。让输入、操作与结果可见，保持对象和物理量的对应。
5. **根据观看反馈修改。** 没达到预期就修核心构思、实现或节奏，不扩成长片，不靠堆光效掩盖问题。记录实际看过、听过和检查过什么。
6. **做成之后再提炼。** 整理完整执行 prompt，并让另一个模型拿到明确的输入文件后试跑；根据实际遗漏和返工修订。

## 最终交付

- 一个经我观看后值得保留的短镜头，以及可编辑源码和重建命令。
- 简洁的参考分析、实现选择、失败原因与检查记录。
- 一份已填写完整的执行 prompt：目标、科学假设、逐段画面动作、关键视觉决定、资产路径、工具与命令、允许调整的范围、验收标准。不是空白模板，也不依赖原对话中未交接的信息。

## 工作边界

- 不先建立大型仓库、平台、风格库、多套 Skill 或长篇规范。当前只推进一个镜头。
- 不把模型署名、“一句话生成”、宣传文案或第三方拆解当作完整制作证据。
- 不默认二维图表，也不强制三维、电影光效、历史故事或生活类比；表现方式服务解释。
- 主动承担研究与视觉设计，不要求我先写专业导演提示词；只询问影响方向的关键选择。
- 付费工具或 API 先明确预算。不创建、不重建、不上传 GitHub 仓库。

## 最小组织

只保留目标说明、研究记录、当前镜头源码与资产、输出、反馈与检查；样片做成后再加入执行 prompt。

**请先提出本次研究范围、少量候选参考和一个具体小实验，不要直接编写整套制作规范。**
